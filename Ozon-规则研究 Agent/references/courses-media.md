## 3. 官方回放：买家忠诚度

> 官方回放：[如何提高买家对品牌的忠诚度](https://www.youtube.com/watch?v=W0E-Ns3lgjc)，Ozon для партнёров，2023-09-07；结构核验日期：2026-08-03。

官方时间轴覆盖：忠诚计划能力与分析、营销工具、Ozon 银行合作带来的附加奖励、接入条件、费用和问答。

蒸馏：

- 忠诚计划不是单纯发券，而是“目标人群—奖励机制—复购行为—成本”闭环。
- 必须把平台/银行承担的奖励与卖家承担的折扣分开核算；不能把所有买家优惠都记为卖家营销费。
- 评估至少观察加入计划人数、活跃/复购买家、奖励成本、增量订单和毛利，而不只看 GMV。
- 费用和接入条件属于动态商业规则；项目只保存计划配置与结果事实，不硬编码旧视频中的费率。

## 4. 官方回放：推广工具组合

> 官方回放：[如何设置推广](https://www.youtube.com/watch?v=U0aOk5ITLAM)，Ozon для партнёров，2023-06-29；结构核验日期：2026-08-03。

官方时间轴覆盖：互联网与平台流量、搜索结果形成、流量模板、搜索推广、评价换积分、促销、外部推广、总结与问答。

蒸馏：

- 推广是组合问题：商品内容和价格决定转化基础，搜索/展示工具带来流量，评价与促销影响信任和购买决策。
- 不能用“开广告后销量增长”直接推断广告增量；需保留自然流量、活动、价格变化和库存可售性作为对照。
- 外部推广必须保存落地页、UTM/归因标识、投放成本、会话、加购、订单和毛利；平台内外口径要分开。
- 2023 年视频中的具体工具名称和操作路径可能已经变化，实施以当前后台和官方知识库为准。

## 5. 官方回放：趋势、搜索与买家画像

> 官方回放：[促销分析：趋势、季节性和买家画像](https://www.youtube.com/watch?v=rQoobCTje-k)，Ozon для партнёров，2022-11-22；结构核验日期：2026-08-03。

官方时间轴覆盖：趋势、搜索查询、买家画像、促销分析和问答。

蒸馏：

- 趋势与季节性应作用于补货和促销计划，不能只在活动开始后看销量。

- 买家画像用于分群和假设，不用于识别个人；项目只保存聚合统计，遵守最小化原则。
- 促销评估需要活动前基线、活动期库存、价格、流量、转化、广告支出和退货后的净结果。

## 12. 官方视频：FBO 强制标记商品供应

> 官方视频：[带“诚实标签”标记商品的 FBO 供应](https://www.youtube.com/watch?v=V_ayBHwgL-Y)，Ozon для партнёров，2024-05-14；官方时间轴核验日期：2026-08-03。

官方时间轴覆盖“诚实标签”平台、连接 EDI、不得无标识销售的商品、在商品卡填写代码、在供应申请中检查标识属性，以及官方免费培训。

蒸馏：

- 强制标记是商品、供应和电子单据三域联动：先确认商品是否纳入标记范围，再维护商品卡代码/属性，随后在供应申请中核对标识要求并准备 EDI 单据。
- 缺少 EDI、商品卡代码错误或供应申请标识不一致都应在发运前阻断，不能等仓库验收失败后处理。
- 项目保存 TN VED、标记制度、商品卡标识属性、标识码/聚合码状态、EDI 文件和供应批次之间的可追溯关联。
- 具体纳入类目、代码格式、EDI 运营商和单据要求会变化，实际供货前必须核对当前官方知识库及“诚实标签”平台。

# 覆盖与更新说明

## 当前完成度

已完成 Ozon 卖家知识体系的第一版全域蒸馏：

- Seller API；
- 账户与合规；
- 商品、内容、价格和促销；
- FBO 供应、入仓、库存和订单；
- 财务、费用、账单和对账；
- 搜索、推广和增长；
- 退货、评价、客服、评级和风控；
- 对本项目的产品与数据建议。

知识范围覆盖整个 Ozon 大学，包括 FBS、rFBS、跨境、珠宝、金融服务等；当前项目匹配范围只做 FBO。两种范围必须分开。

## “全量蒸馏”的含义

本文库不是 Ozon 网页的离线复制，也不保存所有截图、字段和长篇规则正文。它覆盖的是完整经营领域，并把内容压缩为：

- 业务对象；
- 生命周期；
- 关键规则；
- 数据关系；
- 决策指标；
- 工程约束；
- 项目价值；
- 风险边界。

## 来源

核心事实入口：

- [Ozon Seller API](https://docs.ozon.ru/api/seller/)
- [Ozon 卖家知识库](https://seller-edu.ozon.ru/)
- 当前仓库的 Ozon 客户端、同步服务、财务账本和页面实现。

Seller API 页面在 2026-07-30 核对到约 487 个唯一端点。接口数量、版本、权限、费率和业务规则会变化。

## 时效性

下面内容执行前必须实时核对：

- 佣金和服务费率；
- 仓储、物流和退货收费；
- 活动规则；
- 类目准入和证书；
- FBO 供应流程和仓库限制；
- API 路径、版本、方法、字段、权限和限流；
- 评级和处罚阈值；
- 合同与税务要求。

## 已知技术障碍

Ozon 卖家知识库主页对自动目录读取存在跳转/连接不稳定，因此第一版采用：

- Seller API 全页能力结构；
- 官方知识库公开栏目和已知专题；
- FBO 业务生命周期；
- 当前项目实现的交叉验证。

这不影响领域级蒸馏，但意味着具体数字和动态规则不能被视为永久快照。

## 维护方式

每次项目要实现新功能时：

1. 在本知识库找到对应业务域；
2. 打开官方当前规则和 API 方法页；
3. 记录核对日期；
4. 更新端点契约、费用映射或规则版本；
5. 增加测试和数据完整性告警；
6. 再进入实现。

# Ozon 更新摘要、新闻与动态规则蒸馏

> 建档日期：2026-08-03。更新摘要用于发现规则变化，不替代当前合同、费率表或专题知识库。每条公告必须保存发布日期、影响域、生效日和后续专题链接。

## 1. 为什么更新摘要必须独立建模

- 公告描述“发生了什么变化”，专题页描述“现在怎么做”，合同/费率附件给出法律与计费依据，三者证据等级不同。
- 仓点、退货流程、促销入口、广告工具和合同可能在数天内变化；把新闻内容永久写进业务逻辑会迅速过期。
- 一条摘要可能同时影响 FBO、商品、促销、评价和活动日历，必须拆成可追踪变更事件。

建议字段：`announcement_id / published_at / effective_at / domain / schemes / summary / source_url / superseded_by / current_rule_checked_at / project_action`。

- OzonGenerator 与照片编辑器增加移动端/在线表格能力；
- 公告推广问答与商品卡审查活动。

项目处理：退货取回流程、仓库主数据、评价订阅、促销日历和内容工具分别生成变更事件。仓库开放日期是历史事实，不意味着今天仍可预约；导入前必须核对当前仓点目录。

## 3. 2025-09-11：促销码效果分析

> 官方来源：[评估促销码效果](https://seller.ozon.ru/media/news/ocenivajte-effektivnost-vashih-promokodov/)，发布日期：2025-09-11；核验日期：2026-08-03。

公告新增“分析 → 促销 → 促销码分析”，支持按活动、促销码或商品筛选，并查看促销码使用次数、订单数、使用到下单转化、销售额及其分布、平均商品折扣和总折扣；平台还会给出效果结论与建议。

项目映射：

- 每个站外渠道/博主使用独立促销码，保存发放、使用、订单、取消、退货和净销售。
- `使用次数 → 订单` 不是完整漏斗，还需成本、毛利和退货后净结果。
- 平台建议作为建议事实保存，不自动执行改价或预算调整。

## 4. 2025-01-16：金融服务合同更新

> 官方来源：[金融服务合同更新](https://seller.ozon.ru/media/news/o-finansovyh-uslugah-novoe-v-dogovore/)，发布日期：2025-01-16，公告自 2025-01-30 更新合同表述；核验日期：2026-08-03。

公告说明每日、每周和提前付款可能在计划日后继续由银行处理最多 3 个工作日；相关服务费在付款后的下一工作日扣除。持有 Ozon 银行贷款期间，合同付款使用 Ozon 银行结算账户，贷款结清后才可在后台修改收款信息。

项目处理：

- 计划付款、平台发送、银行处理中和银行到账是四个不同事实；3 个工作日是当期合同说明，不作为永久 SLA。
- 付款服务费与销售结算分开入账。
- 贷款绑定账户属于合同/金融约束，项目只提示并保存状态，不自动修改收款账户。

## 5. 2026-04-22：新品首批生产与库存风险

> 官方来源：[如何推出新品并计算首批数量](https://seller.ozon.ru/media/boost/kak-vyvesti-tovar-na-marketplejs-i-rasschitat-pervuy-partiyu/)，发布日期：2026-04-22；核验日期：2026-08-03。

官方经营案例强调首批过小会错失需求，过大会冻结资金并形成滞销；应结合 Ozon“卖什么”分析、竞品评价、专业社群信息、生产最小批量、原料交期和完整生产周期判断。案例中的牙膏生产说明某些品类无法用极小批量试产，完整周期可能很长。

项目映射：

- 首批量计算输入包括市场需求、目标份额、转化假设、生产 MOQ、采购/生产/跨境/入仓总交期、安全库存和资金上限。
- 输出必须是情景区间，不是单点“推荐数量”；展示过量库存与缺货两侧风险。
- 竞品评价用于识别未满足需求，不直接复制对方商品内容。

## 6. 动态规则采用原则

1. 公告先进入变更收件箱，按业务域拆分。
2. 找到对应专题页、合同或费率附件并核对当前状态。
3. 标记 `planned / effective / superseded / expired`。
4. 只有当前有效且证据完整的规则才能驱动校验或计算。
5. FBS/realFBS 公告完整归档，但不进入 ozon-workbench 操作能力。

## 7. 2023-08-17：FBO 库存与在途报告增加 IDC

> 官方来源：[FBO 仓库销售报告更新](https://seller.ozon.ru/media/news/fbo-novoe-v-otchyotah-po-prodazham-so-skladov/)，发布日期：2023-08-17；核验日期：2026-08-03。界面路径和颜色阈值属于历史状态。

公告在 FBO 库存周转页与“库存和在途商品”报告中强化 IDC（按当前平均日销量计算当前库存可售天数），并区分：

- IDC：当前库存预计还能销售多少天；
- 周转天数：若按最近 60 天平均库存与销量，平均库存预计覆盖多少天；
- 仓库级 IDC：用于识别同一 SKU 在不同仓库的销售速度差异。

项目映射：

- `days_of_cover = sellable_stock / average_daily_sales`，但同时保存销量窗口、缺货天处理、库存口径和计算时间。
- 当前库存与平均库存是不同分母，IDC 与周转天数不能互换。
- 颜色仅是平台当期解释层；项目保存原值并允许动态阈值，不能把 2023 年绿/红规则写死。
- 仓库/集群差异直接进入补货与调拨建议，不能只看全网汇总库存。

## 8. 2025-02-12：隐藏的 Economy 商品取回与处置

> 官方来源：[在处置前取回隐藏的 Economy 商品](https://seller.ozon.ru/media/news/zaberite-skrytye-ekonom-tovary-do-utilizacii/)，发布日期：2025-02-12；核验日期：2026-08-03。公告中的天数、费率和免费窗口仅作历史快照。

公告描述当时 Economy 商品因平均凑单时间过长而被隐藏，随后可能在隐藏后 90 天进入卖家付费处置；卖家可从“FBO → 取回与处置”按仓创建取回申请，选择自提或配送。公告还列出当期分拨中心/快递/提货点配送费、暂存免费天数、逾期保管费和处置节点。

项目处理：

- Economy/量子凑单属于特殊销售机制，需与普通 FBO 库存分开标识。
- 对隐藏、等待取回、在途、到达取回点、已领取和已处置建立事件时间线。
- 任何处置倒计时必须来源于当前合同和商品状态；旧公告的 90 天、价格和免费窗口不可用于今天自动计算。
- 取回申请按仓拆分，保存申请、商品行、方式、目的地、费用、更正交易和实际领取证据。

## 9. 2024-12-04：境外订单、本地化指数与跨国供应

> 官方来源：[Ozon Marketplace 官方频道](https://t.me/s/ozonmarketplace)，2024-12-04 公告；核验日期：2026-08-03。该公告是历史快照，不证明当前资格、国家、仓点或优惠仍有效。

公告当时说明：俄罗斯卖家发往哈萨克斯坦和白俄罗斯的订单可能影响本地化指数；从目的国本地仓发货会提高本地化，从俄罗斯发货会降低；平台可能以卖家名义直接发货，也可能先收购商品。公告还说明不同国家供应资格可能依税制和 EDI 条件变化，并可使用跨仓把货交到境外仓。

项目处理：

- 公告拆成“指标规则、销售法律结构、供货资格、跨仓服务、仓储优惠”五类变更，不能作为一条布尔开关。
- 本地化指标是经营算法；平台收购是交易/单据事实；两者不得混淆。
- 国家、税制、EDI、商品例外、起止日期与费用均版本化；优惠到期后保留历史，不回写订单。
- 当前项目只识别跨境数据，不实施境外供应或 FBS/realFBS 操作。

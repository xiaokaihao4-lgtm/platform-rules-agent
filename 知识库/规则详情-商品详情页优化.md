# 🛠️ WB 商品详情页优化规则（官方 2026-08-13 更新）

> 来源: WB帮助中心「如何优化商品详情页」 更新日期 8/13/2026
> 核心原理: 搜索时算法自动挑选最符合搜索请求的详情页 → 排名靠前 → 购买机会大

---

## 一、收集搜索请求（挖词）

研究用户常用搜索词，官方推荐工具：

| 工具 | 用途 | 说明 |
|------|------|------|
| **Yandex.Wordstat** | 俄语词频统计 | 免费，输入词看每月搜索量 |
| **Google Trends** | 趋势对比 | 免费 |
| **WB搜索请求报告** | 平台内真实搜索词 | 后台：分析→搜索分析 |
| **商品对比报告** | 对比竞品卡片表现 | 后台 |

## 二、优化页面内容（埋词）

排名受 **标题、描述、属性** 三方面影响。

### 标题规则（重点⚠️）

> 选择最贴切的关键词添加到标题。**避免同义词、重复词、不能准确描述商品的词组。**

官方错误示例：
- ❌ `Чехол для телефона смартфона прозрачный`（透明手机壳）→ **смартфона 和 телефона 是同义词，删一个**
- ❌ `Хайлайтер тени для век блестящая палетка для макияжа лица`（高光眼影闪耀面部彩妆盘）→ 细节描述/使用建议/主观评价放描述里，不放标题

### 描述规则

- 写详细描述，突出**商品特点 + 对买家的价值**
- 关键词**自然融入**（不是堆砌）
- 检查拼写和语法错误
- **有 JAM 订阅 → 用 AI 描述生成工具**（根据关键词自动生成）

### 属性规则

- **填满所有属性字段** ← 最易忽视但影响筛选
- 下拉列表有提示选项 → **选一个**（提高被筛选到的概率）

## 三、利用附加功能

| 功能 | 作用 | 权限 |
|------|------|------|
| **富媒体内容** | 更详细生动的商品描述 | 所有卖家 |
| **图片标记** | 让买家了解你的其他商品（交叉推荐） | 仅 JAM 订阅 |
| **商品详情页推荐** | 扩大曝光范围 | JAM 订阅 |

## 四、持续监控（关键）

> **定期查看商品详情页在搜索结果中的排名位置。如排名下降，检查页面内容并考虑优化方向。搜索结果动态变化，优化工作需持续进行。**

---

## 落地检查清单（每次上新/优化用）

```
□ 1. 挖词：Yandex.Wordstat + WB搜索请求报告（核心词+长尾词）
□ 2. 标题：核心词 + 差异化卖点，无同义词堆砌
□ 3. 描述：AI生成 → 人工改 → 关键词自然融入
□ 4. 属性：全部填满，下拉选项选上
□ 5. 富媒体：加推广模块
□ 6. 图片标记：JAM用户交叉推荐
□ 7. 排名监控：每周看一次排名位置
```

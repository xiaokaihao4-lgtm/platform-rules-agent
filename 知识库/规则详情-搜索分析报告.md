## 一、报告《搜索请求：您的商品》

> 路径：分析 → 搜索分析 → "搜索请求：您的商品"  
> 需要 Jam 订阅（免费版仅7天基础数据）

### 核心指标
| 指标 | 含义 |
|------|------|
| **平均排名** | 算术平均排名（仅计入加购/进入详情页的展示） |
| **中位排名** | 中间值排名，抗极端值干扰 |
| **可见性** | 买家看到商品的概率%（根据平均排名计算） |
| 近7天排名 | 按天显示平均排名+搜索订单数 |
| 高于n%卖家 | 访问/加购/下单数量超过竞争对手的比例 |

### 免费版 vs Jam版
| 维度 | 免费版 | Jam标准版 | Jam高级版 |
|------|:--:|:--:|:--:|
| 时间范围 | 仅7天 | 365天 | 365天 |
| 搜索请求数 | ❌ | 30个 | **100个** |
| 指标 | 排名+加购转化率+价格 | 完整 | 完整 |
| 按请求分析 | ❌ | ✅ | ✅ |
| 替代商品编号 | ❌ | ✅ | ✅ |

### 报告组件
1. **评级与排名** — 卖家评级、推广商品数、平均排名、中位排名、排名区间分布
2. **可见性与商品点击** — 可见性%与点击关系图（日/周/月）
3. **地区** — 买家地区分布+平均配送时间
4. **表格** — 商品×搜索请求的详细数据

### 搜索排名因素（7+因素红绿灯）

🟩=良好  🟥=有待改进  ⬜=无法计算

#### 按商品详情页维度：
| # | 因素 | 说明 |
|---|------|------|
| 1 | 访问到下单转化率 | 订单÷访问×100%，vs同类商品平均 |
| 2 | 商品销售额(₽) | 最近一周权重更高，缺货不重置 |
| 3 | 参与促销活动 | 数周平均值，缺货不重置 |
| 4 | 物流配送 | 配送区域+时间 vs 其他卖家 |
| 5 | 商品评分 | 买家评论评分+评价总数 |
| 6 | 卖家评级 | 店铺所有商品综合评级+总评价数 |
| 7 | 推广选项 | "提升排名"选项是否开通 |

#### 按搜索请求维度（需Jam）：
| # | 因素 | 说明 |
|---|------|------|
| 1 | 展示到下单转化率 | 订单÷展示×100%，vs该搜索词头部商品 |
| 2 | 展示到访问转化率 | 访问÷展示×100%，vs该搜索词头部商品 |
| 3 | 访问到下单转化率 | 订单÷加购×100%，vs该搜索词头部商品 |
| 4 | 正品验证 | 品牌搜索中身份是否验证 |
| 5 | 商品评分 | 买家评论评分 |

### 表格中的列
- 搜索请求频次、平均搜索排名、展示次数
- 点击转换率、从搜索进入详情页、从搜索加购
- 搜索加购转化率、搜索订单量、搜索下单转化率
- 搜索曝光率、当前折后价

### ⚠️ 关键约束
- 仅统计买家**进入详情页或加购**时的排名
- 平均配送时间影响排名**30-40%**
- "快速预览"加购不计入点击
- 缺货后恢复，转化率从清零前最后值继续（不归零）
- 可疑交易商品不计入统计

## 二、报告《WB搜索请求》

> 路径：分析 → 搜索分析 → "WB搜索请求"  
> 视角：**全平台**热搜词，非仅你的店铺

### 用途
- 了解买家当前搜索趋势
- 发现高需求低竞争细分市场
- 优化SEO和推广策略

### 免费版 vs Jam版
| 指标 | 免费版 | Jam扩展版 |
|------|:--:|:--:|
| 搜索请求 | ✅ | ✅ |
| 变化趋势 | ✅ | ✅ |
| 请求总次数 | ✅ | ✅ |
| 日均请求数 | ✅ | ✅ |
| 下单最多品类 | ✅ | ✅ |
| 商品点击(详情页打开) | ❌ | ✅ |
| 加购次数 | ❌ | ✅ |
| 加购转化率 | ❌ | ✅ |
| 搜索结果商品数量 | ❌ | ✅ |
| 下单商品数 | ❌ | ✅ |
| 下单转化率 | ❌ | ✅ |

### 数据过滤规则
网页报告最多**500行**，不显示以下类型：
- 商品编号格式的搜索词（如"123456777"）
- 替代商品编号（如"WW[6]"）
- 含多余空格/特殊符号的词
- 带来用户行为<30次的词

### XLSX导出
- 最多 **100,000行**
- Jam版多选项卡：参数概览+计算公式说明+详细数据

### 分析周期
| 选项 | 天数 |
|------|:--:|
| 昨天 | 1 |
| 一周 | 7 |
| 一月 | 30 |
| 一个季度 | 90 |

### ⚠️ 注意事项
- 不显示当日数据
- 搜索结果因地区而异，报告取最常出现值
- 搜索框对词形变化敏感（单复数不互通）
- 可点击品类跳转"市场分析"报告（需高级版Jam）

# 🔑 WB 店铺登录模式（共享规范）

> **所有 WB 相关 Agent 统一遵守的登录规范**（2026-08-22 实战验证）
> 适用：wb-data-extract / 网页提取 / 数据看板 / 规则研究 等所有需要访问 WB 后台的脚本

---

## 唯一正确的登录方式

**独立 Chrome profile + Playwright，`headless: false`**

```javascript
const USER_DATA_DIR = "/Users/haoxiaokai/.hermes/skills/productivity/wb-data-extract/wb_chrome_profile";
const CHROME_BIN = "/Applications/Google Chrome.app/Contents/MacOS/Google Chrome";

const context = await chromium.launchPersistentContext(USER_DATA_DIR, {
  executablePath: CHROME_BIN,
  headless: false,          // ⚠️ 必须非无头！headless 不加载登录 cookie
  locale: "zh-CN",
  args: ["--no-sandbox", "--disable-blink-features=AutomationControlled"],
  viewport: { width: 1920, height: 1080 }
});
// ... 操作 ...
await context.close();      // 铁律：正常关闭，让登录态写回磁盘
```

## 铁律（违反必出事）

| # | 铁律 | 后果 |
|---|------|------|
| 1 | **绝不用 `headless: true`** | headless 不加载 profile 登录 cookie → 必然跳登录页 |
| 2 | **绝不调用 cleanProfileLocks() / 删锁文件** | 删 SingletonLock/Cookie 必退登 |
| 3 | **正常 `context.close()` 收尾** | 让登录态写回磁盘；kill -9 强杀会丢登录态 |
| 4 | **🔴 同一 profile 同时只允许一个任务** | 两个脚本抢同一 profile → 互相锁死 → "正在现有的浏览器会话中打开" → 登不上 |
| 5 | **登录态约 1 个月过期** | 每周开一次 WB 后台保活；过期只能重登（token 在 sessionStorage，复制救不回） |

## 并发冲突检查（开任务前必做）

```bash
# 查有没有其他任务正在用这个 profile
ps aux | grep wb_chrome_profile | grep -v grep
# 有输出 = 有任务占用 → 等它结束，或温和 TERM（不要 kill -9）
```

**症状识别**：
- 报错 `Target page, context or browser has been closed`
- Chrome 日志显示 `正在现有的浏览器会话中打开`
- 用户反映"店铺登不上"

**根因**：两个脚本同时 `launchPersistentContext` 同一个 `wb_chrome_profile` → profile 锁死。

## 登录成功判定

```javascript
await page.goto("https://cmp.wildberries.ru/campaigns/list", { waitUntil: "domcontentloaded", timeout: 60000 });
// URL 含 "seller-auth" → 登录态失效
// URL 正常 → 登录成功
```

## 店铺登录验证

| 后台 | URL | 判定 |
|------|-----|------|
| 卖家主后台 | `seller.wildberries.ru` | 能进 = OK |
| 推广后台 | `cmp.wildberries.ru/campaigns/list` | 能进 = OK |
| 两者都跳 `seller-auth` | — | 真过期，需重登 |
| 只一个跳 | — | 页面问题，不是登录问题 |

## 登录态维护

- 每周开一次 WB 后台保活（防 1 个月过期）
- 过期后：让用户手动登录一次（手机号+验证码，只有用户能做）
- 登录脚本：`node /tmp/wb_relogin.js`（弹 Chrome 窗口让用户登录）

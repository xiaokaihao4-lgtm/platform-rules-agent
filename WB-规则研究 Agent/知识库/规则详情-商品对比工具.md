# 规则详情-商品对比工具（Сравнение карточек）

> 来源：官方《Отчёт «Сравнение карточек»》（更新 08.09.2026）+ FAQ（07.09.2026）+ 官方研究文章
> 整理：2026-09-10

---

## 一、是什么

对比 **2-5 张卡片**（自己的或任何卖家的）的指标、动态、搜索词、库存区域。用于：对标竞品、找差距、验证调价/内容动作的效果。

**入口**：分析 → 商业发展分析 → 商品对比（Аналитика развития бизнеса → Сравнение карточек）

## 二、使用条件与消耗

| 项目 | 规则 |
|------|------|
| 权限 | Jam 订阅（推荐列表需「Продвинутый(高级)」或「Премиальный(尊享)」）|
| 消耗 | 每次对比消耗 1 次额度；**72 小时内可无限次重复查看 + 下载 XLSX** |
| 推荐列表限额 | 每天最多 **100 次请求**——每点一次「应用」算 1 次，别乱点 |
| 周期切换 | 今天/周/月/季度——**切换周期不额外消耗** |
| 报告时效 | 72 小时；过期后重看需再消耗 1 次 |
| 数据性质 | 官方声明：仅供参考 |

## 三、两种推荐模式（关键区别）

### A. 按品类推荐（по предмету）—— 看"品类头部"
4 个排序选项：

| 选项 | 官方含义 |
|------|---------|
| 按销售额 | 近 1 个月**成交金额**最高的 top-50 |
| 按单品成交价 | 近 1 个月**成交单价最高**的 top-50（价格调研用，跟销量无关）|
| 按热销价格段的成交数量 | **主流价格带内**成交件数最高的 top-50（找主销价格带的销量王）|
| 按总成交数量 | 全品类**成交件数**最高的 top-50 ⭐ 直接看销量 |

**局限**：不能按"跟你价格差不多"筛；卡片列表不显示价格。

### B. 按货号推荐（по артикулу）—— ⭐ 找"同价竞品"用这个
输入一张卡片的货号，系统推荐**同品类且最接近**的卡片，5 种相似维度：

| 相似类型 | 官方含义 |
|---------|---------|
| 按销售额相似 | 近 1 月收入**略高于**你指定卡片的 |
| 按成交件数+成交价相似 | 成交件数和成交价都接近的 ⭐ |
| **按成交件数+成交价+名称相似** | 名称也相似 = **同款同价同销量** ⭐⭐（找直接竞品最精准）|
| 按销售额+名称相似 | |
| 按名称相似 | 只按名称（计算相似度，只取有意义词）|

## 四、报告内容

### 1. 动态图表（сurrent vs 上一周期）
- 显示所对比卡片的指标变化；可按**日/周/月**细化
- 指标：展示、进入卡片、CTR、加购、加购转化率、下单件数、下单金额、下单转化率、**成交件数**、**成交金额**、**成交率**、取消、**买家中位价**、平均搜索排名

### 2. 表格三块
| 块 | 内容 |
|----|------|
| 指标 | 价格（min/max）、买家中位价、卡片创建日期、评论数、展示、CTR、平均送达时间、平均搜索排名、加购、下单、成交、成交率、取消 |
| **搜索请求** | 买家**靠哪些词下单**（可对比双方）——SEO 借鉴金矿 |
| 仓库区域 | 库存、在途、区域分布 |

### 3. "真实销量"关键字段
- **выкупили товаров**（成交件数）← 最直接的销量数字
- **выкупили на сумму**（成交金额）
- **процент выкупа**（成交率 = 成交÷(成交+取消)）← 看产品"虚不虚"
- **медианная цена покупателя**（买家中位价，含 WB 折扣、**不含**钱包折扣）

⚠️ 成交/取消口径按"**成交日/取消日**"计算，与销售漏斗（按订单日）不同——两报告数字对不上是正常的。

## 五、官方研究：卖家都用它干什么

- 样本：20,000+ 卖家
- **最流行策略（84.5%）：自己的卡 vs 同品类别人的卡**（控位置、防掉销量）
- 第2：分析**自己没做的品类**的别人的卡（找新方向）
- 第3：分析**自己品类里别人的卡**（跟随趋势）
- 高 GMV 卖家使用率更高

## 六、推荐工作流：找同价竞品 + 看整体变化（一次搞定）

```
1. 商品对比页 → 选「按货号推荐」→ 输入自己餐椅货号
2. 选「按成交件数+成交价+名称相似」（备选：成交件数+成交价）
3. 点「应用」→ 从结果挑 2-4 个竞品 → 加上自己的 → 共 2-5 张
4. 「商品对比」生成报告（消耗 1 次；72h 内免费重看）
5. 周期选「月」→ 图表看双方 成交件数/成交金额 曲线（当前 vs 上一期）
   = 销量变化对比 + 整体变化，一次看完
6. 表格看差距：买家中位价、成交率、平均排名、评论数、搜索词
7. 原因归因 → 事件日历（改价/广告/促销/评价事件）
```

## 七、注意

- 推荐列表卡片**不显示价格**——判断"价格是否接近"要靠报告生成后的中位价字段
- 72 小时后报告失效，重看要再消耗 1 次；生成后尽快导出 XLSX
- 每点一次「应用」消耗每日 100 次推荐请求额度

## 一、自动促销折扣深度（Глубина скидки в автоакциях）

### 四级折扣深度

| 深度 | 俄文 | 排名加成 | 折扣力度 |
|------|------|:---:|:---:|
| 轻度 | Лёгкая | 低 | 最小折扣 |
| 中度 | Умеренная | 中 | 中等折扣 |
| 深度 | Глубокая | 高 | 较大折扣 |
| 最大 | Максимальная | 最高 | 最深折扣 |

### 核心规则

- 🔴 **默认「最大」深度！** 不主动调整 = 以最深的折扣参与 → 利润损伤最大
- 折扣越深 → 搜索排名越靠前
- 每个促销活动的深度等级数量不同（2/3/4级，甚至不提供）
- ⚠️ **不是统一折扣**：同一深度下不同商品的折扣%可能不同
- 每个深度的折扣%只在该促销活动中计算，不跨活动通用

### 操作限制

- 深度必须在**促销开始前5小时**更改 → 开始后不可改
- 如果在「最大」深度下提价导致价格 > 计划价 → **自动踢出促销**（不会降到「深度」级）
- 排除商品按深度分别保存 → 切换深度后需重新配置

## 二、WB 俱乐部折扣（Скидка для участников WB Клуба）

### 核心规则

- 给 WB 俱乐部会员的**额外折扣：3% – 31%**
- **在卖家折扣后叠加**计算（不是原价）

```
例: 商品1000₽ → 卖家折扣20% = 800₽
    → 俱乐部折扣10% × 800 = 80₽
    → 最终到手 = 720₽（买家实际付）
```

### 排序加成

- 条件：**≥ 50%商品（按卡片数）设置了 ≥ 5% 俱乐部折扣**
- 效果：这些商品排名提升

### 操作

- 路径：价格与折扣 → WB俱乐部折扣标签
- 支持 Excel/XLSX 批量设置 / API（>100万商品）

## 三、自动促销（Автоакции）

### 卖家控制手段

| 工具 | 作用 |
|------|------|
| 最低价格 | 商品在自动促销中不低于此价（除非卖家主动降价）|
| 折扣锁定 | 阻止自动促销折扣应用到指定商品 |
| 排除商品 | 调高价格 > 促销计划价 |

### 限制

- 上架 ≤ 15天的新品**不可参与任何促销**
- 多尺码商品不会**自动**进入 → 需手动加

## 四、结论：补贴到底是谁出

| 折扣类型 | 谁承担 | 卖家控制 |
|----------|:---:|:---:|
| 自动促销折扣 | **卖家** | 选深度、设最低价、锁定 |
| WB 俱乐部折扣 | **卖家** | 设比例(3%-31%)、是否参与 |
| 普通促销折扣 | **卖家** | 设价格≤促销价 |
| WB 给的流量/排名加成 | **WB 补贴** | ✗（无直接控制） |

**WB 的"补贴"不是钱——是流量和排名加成。** 所有折扣金额全部由卖家承担。你降价多少，买家就省多少，WB一分不出。

## 五、对你最关键的一条

**默认「最大」折扣深度 = 你可能在不知情的情况下以最深的折扣在跑。**

如果商品参加了自动促销且你没调过深度 → 默认就是最大深度 → 折扣最深 → 利润最低。

**立即检查：**
- 路径：促销日历 → 找到你的商品参与的活动 → 看当前深度
- 如果显示「Максимальная」而你不想打那么深 → **在促销开始前5小时** 降到「Глубокая」或「Умеренная」

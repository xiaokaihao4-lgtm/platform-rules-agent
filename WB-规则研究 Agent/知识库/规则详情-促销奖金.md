# 规则详情-促销奖金（Промобонусы）

> 来源：WB 官方帮助中心 + 卖家生态资料交叉验证（sellermate.io / uniseller.io）
> 整理日期：2026-08-31
> 状态：✅ 已验证（多源一致）

---

## 一句话定义

**促销奖金（Промобонусы）= WB 平台额外赠送的广告预算**，1 промобонус = 1 卢布广告费，只能用于平台推广工具（WB Продвижение / WB Медиа），**不能提现、不能转出、不能当货款**。

## 在预算体系中的位置

推广预算有三个独立来源：

| 来源 | 性质 | 说明 |
|------|------|------|
| 余额（Баланс） | 平台按销售额**预借** | 从未来销售扣回，75%周二/25%周四入账 |
| 账户（Аккаунт） | 卖家自己充值 | 只能用于推广，不可提现 |
| **促销奖金（Промобонусы）** | **平台白送** | 有过期时间，分包管理 |

## 奖金从哪来（6 个渠道）

| 来源 | 说明 |
|------|------|
| 新卖家注册 | 注册后赠送，零成本测试推广 |
| 完成推广任务 | 「我的任务」(Мои задания) 不定期任务，完成后发放 |
| 参加促销的补偿 | 如参加「超级价格日」让利 20%，平台可能用奖金补一部分 |
| 个人经理成长策略 | 有客户经理的卖家按条件发放（增长/开广告/扩品类） |
| 平台故障补偿 | 物流计算错误、入库延误等虚拟补偿 |
| 平台营销活动 | 周年庆/大促期间随机发放 |

## 在哪查看

- **推广后台 → 我的任务（Мои задания）**：可用余额、分包情况、每包燃烧日期、已花/已入、操作历史
- **推广 → 余额（Баланс）**：充值与消耗流水
- **费用历史（История затрат）**：可按 WB Медиа / WB Продвижение 分开分析

## 使用规则

1. **可覆盖最高 99% 活动预算**（具体比例看奖金包条款）
2. **自动活动默认优先烧奖金**——系统先扣奖金再扣真实余额
3. **手动活动需勾选「使用奖金」**（Использовать бонусы）才会用
4. **有过期时间**——分包管理，每包有燃烧日期，常见 7 天起，到期未用作废
5. **烧完即停**——奖金过期/耗尽后活动余额不足则自动暂停
6. **⚠️ 奖金花费可能不计入促销活动的真实广告支出考核**——部分活动考核"卖家实际广告花费"时，奖金支出不算

## 实操策略（避坑）

### 拿到奖金时的正确操作

1. **先暂停自动活动**再等奖金到账——否则系统一拿到奖金就按原出价狂烧（一夜烧光是真实案例）
2. **建手动活动 + 勾选「使用奖金」+ 设日限额** = 奖金总金额，全程可控
3. **出价可以比正常低 10-15%**——不是真钱，不用激进抢位
4. **把奖金当测试预算**：验证新关键词、新链接、新品，跑通了再上真钱放量
5. **优先投已有销量和评价的卡片**——转化基础好，奖金不白烧

### 危险行为（会导致损失）

- ❌ 奖金到账前不暂停自动活动 → 系统自动烧光
- ❌ 当"免费钱"拉高出价 → 算法对真钱假钱一视同仁，高标价=加速燃烧
- ❌ 多活动并行接奖金 → 烧钱速度成倍放大
- ❌ 刷量套现（假账号/机器人点击）→ WB 监控异常点击模式，轻则封广告户重则冻结全部回款

### 税务提醒（在俄注册主体适用）

- 奖金 = **实物形式收入**，年累计超 4000₽ 需申报纳税
- ИП（USN「收入」）计入应税基数；ООО（ОСНО）计入营业外收入
- 中国卖家（非俄税务居民主体）不适用俄个税申报，但公司主体在俄的需财务处理

## 与本知识库其他规则的关联

- 「预算与支付」（8/11 更新）：统一账户 = 余额 + 账户，奖金是第三来源
- 「广告统计」：区分奖金花费与真实花费，算推广费用占比时**只用真实花费**
- 「促销折扣与补贴规则」：参加促销拿奖金补偿时，先算让利是否覆盖得住

## 快速自检清单

```
□ 查过 Мои задания 看有没有待领的奖金？
□ 每包奖金的燃烧日期记下了吗？
□ 奖金到账前自动活动已暂停？
□ 手动活动已勾选「使用奖金」？
□ 出价已按"假钱"标准下调 10-15%？
□ 推广费用占比计算时已剔除奖金花费？
```

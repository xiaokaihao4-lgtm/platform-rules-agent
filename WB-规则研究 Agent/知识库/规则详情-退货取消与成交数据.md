# 📊 WB 退货/取消/成交数据准确性规则

> 来源: WB中文帮助中心「FBS订单取消与退货」分类 + 推广体系统计指标
> 更新: 2026-08-10

---

## 一、订单取消的三种路径

### 1. 买家取消（1小时内）
- 买家下单后 **1小时内** 可自行取消订单
- 取消后移入「配货任务」→「已取消」选项卡
- ⚠️ **库存不会自动恢复** — 必须手动到「库存管理」修改
- 罚款：**无**

### 2. 自动取消（120小时超时）
- 买家下单后 **120小时内** 未发货/未完成仓库分拣 → 系统自动取消
- 罚款：**有**（按罚款清单第14条，四倍佣金，上限商品价50% / 单件3,000₽）

### 3. 卖家取消
- 卖家在「新订单」或「配货中」阶段手动取消
- 罚款：**有**（同上，四倍佣金）
- 例外：如果是库存为零导致的取消 → **不收罚款**

## 二、退货流程（买家收货后）

### 退货申请期限
- 买家收货后发现缺陷/不合适 → 可在 WB.ru 个人账户提交退货申请
- 路径：订单 → 退货
- **法律层面**：俄罗斯消费者权益保护法第19条 — 瑕疵商品可在购买后 **2年内** 退货

### 卖家处理退货申请
- 路径：卖家平台 → 供货与订单 → 买家退货
- 两个标签页：「审核中」（未处理）+「归档」（3个月内已处理）
- **处理期限：5天内**
- ⚠️ 5天未处理 → **自动批准退货**

### 退货4种处理选项
| 选项 | 含义 | 适用场景 |
|------|------|---------|
| 拒绝 | 买家保留商品，不退款 | 商品无问题 |
| 同意无需退货 | 退款，买家保留商品 | 有缺陷无法二次销售 |
| 核准并提取货物 | 退回自提点后退款 | 可二次销售的商品 |
| 批准退货并检查瑕疵 | 退货到仓库检查后退款 | 不可退货类目（内衣/袜子/电子产品等）|

### 退回后状态
| 状态 | 含义 |
|------|------|
| 已创建 | 卖家已创建退货申请 |
| 运输至自提点途中 | 正在运往指定自提点 |
| 待领取 | 已到自提点，**7天内**领取，否则销毁 |
| 未配货 | 仓库没找到商品，退货取消 |
| 存储已过期 | 超过7天未取，已销毁 |
| 客服中心取消 | 卖家要求取消 |

## 三、推广统计中的「成交」「取消」「订单」定义

### 推广后台指标定义（官方规则）

| 指标 | 定义 | 关键细节 |
|------|------|---------|
| **展示次数** | 商品被看到的次数 | — |
| **点击次数** | 进入详情页/加购/收藏 | 仅搜索结果页的点击 |
| **CTR** | 点击÷展示×100 | — |
| **加购次数** | 含14天关联转化 | 买家14天内加购店铺其他商品也计入 |
| **订单数** | 含14天关联转化 | 买家14天内下单店铺其他商品也计入 |
| **取消数** | **技术原因未送达 + 1小时内取消** | ⚠️ 不含120小时超时和卖家取消 |
| **订单金额** | — | — |
| **花费占比** | 花费÷订单金额×100 | <100%为盈利 |

### ⚠️ 数据不准的核心原因

#### 问题1：推广后台的「取消数」≠ 实际取消数
推广统计中的「取消数」**只包含两类**：
1. 技术原因未送达的取消
2. 买家1小时内取消的订单

**不包含**：
- ❌ 120小时超时自动取消
- ❌ 卖家手动取消
- ❌ 买家收货后退货

→ 所以推广后台的取消数永远比实际少。

#### 问题2：「订单数」含14天关联转化
推广后台的「订单数」不是这个商品的实际订单数，而是：
- 买家点击推广商品后 **14天内** 加购/下单的 **你店铺任何商品** 都计入

→ 所以推广后台的订单数可能比实际多（包含了其他SKU的订单）。

#### 问题3：「实际成交」数据延迟
- 买家下单 ≠ 成交
- 买家需要实际付款确认
- FBS模式下还需等仓库收货确认
- 成交数据通常延迟 **1-3天** 才在统计中更新

#### 问题4：退货数据不在推广统计中
- 推广统计 **不显示** 买家收货后的退货
- 退货数据在单独的报告：「供货与订单」→「买家退货」
- 退货报告只覆盖 **3个月**

## 四、去哪看准确数据

| 你想知道的 | 推广统计能看吗 | 正确的数据来源 |
|-----------|:---:|-------------|
| 广告展示/点击花费 | ✅ | 推广 → 统计 |
| 这个商品总共下了多少单 | ❌ 含关联 | **供货与订单 → 配货任务** |
| 买家1小时内取消了多少 | ✅ | 推广 → 统计 → 取消数 |
| 120小时超时取消 | ❌ | **供货与订单 → 配货任务 → 已取消** |
| 买家收货后退货 | ❌ | **供货与订单 → 买家退货 → 归档** |
| 实际成交（已付款） | ⚠️ 延迟 | **供货与订单 → 配货任务 → 已完成** |
| 退回仓库的商品 | ❌ | **供货与订单 → 退货与移库** |
| 准确的ROI | ❌ 需手算 | 推广花费 vs (已完成订单销售额 - 退货退款) |

## 五、准确计算ROI的正确方法

```
真实ROI = 实际销售额 ÷ 广告花费

其中：
实际销售额 = (已完成订单的销售额) - (退货退款的金额)

数据来源：
- 广告花费 → 推广 → 统计
- 已完成订单 → 供货与订单 → 配货任务 → 已完成
- 退货退款 → 供货与订单 → 买家退货 → 归档
```

### 数据对账SOP
1. 推广统计看花费和展示（这个是准的）
2. 配货任务看实际订单数和成交数（比推广统计准）
3. 买家退货看退货退款（推广统计完全不含这个）
4. 手动算：真实成交 = 推广订单数 - 1小时内取消 - 120小时超时 - 收货后退货
5. 真实ROI = (真实成交 × 客单价) ÷ 广告花费

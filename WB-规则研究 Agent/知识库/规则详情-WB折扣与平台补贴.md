# 🏷️ WB 折扣（Скидка WB）与平台补贴机制

> 来源：WB 官方帮助中心《Скидка WB》+《Скидка для участников WB Клуба》（更新 11.09.2026 / 18.05.2026，官方原文抓取）
> 整理日期：2026-09-09（本店诊断后补全）
> 状态：✅ 已验证（官方原文）

---

## 一、核心机制（卖家最常误判的一条）

**「买家看到的价格 ≠ 你的定价」**：WB 会把平台自己的补贴折扣加进去，买家看到的价格**已含 WB 补贴**。

**官方原文（11.09.2026 最新）：**

> **Скидка WB — 这是 WB 自掏腰包给买家的额外折扣。买家看到的价格已含此折扣。**
> **但无论 WB 折扣多大，你收到的货款一律按「你的折前价 + 你设的卖家折扣」结算，不计入 WB 折扣。**
> **折扣力度由 WB 自己定，会随时间变化。**

**翻译成卖家语言：**

```
你的定价：   5 000 ₽
买家看到价： 4 500 ₽（WB 补贴了 500）
你的到款：   5 000 ₽（按你的定价算，不计那 500）

差额 500 = WB 出的补贴，进不了你的口袋，但拉低了买家到手价、抬高了转化
```

**→ 用户之前"所有折扣卖家承担"的印象是错的**：那只适用于「卖家自己设的促销让利」，不适用于 **WB 折扣**（平台自费）。

---

## 二、WB 折扣的构成与变化规律（关键）

### 1. 基础部分（WB 定，你控制不了）
- 力度 WB 自己定，会变
- **主动收缩** → 买家到手价变贵 → 转化下降
- **这是全店层面的变量**：WB 补贴收缩会影响你所有商品，不全是一个品的问题

### 2. 广告加成部分（你通过推广能争取，最多 +10%）
**官方原文：**
> WB 折扣的大小取决于**你最近 14 天的广告/推广花费占比**，**每天更新**。推广可贡献的最高额外 WB 折扣 = **10%**。

**规则细节：**
- **连续投入**（每天小额投）> 最后一天突击投——同样总花费，连续投拿到的加成更高
- **促销奖金（промобонусы）不计入**这部分花费占比
- 只对**特定类目**开放（官方清单含儿童用品等，会扩展）
- 加成作用于**该品类所有商品**（不只你投的那个品）
- WB 推广后台活动页有「额外 WB 折扣」widget 显示当前加成

## 三、WB 俱乐部折扣（Скидка WB Клуба）——另一个"前端价<定价"来源

| 项目 | 说明 |
|------|------|
| 力度 | 可设 **3%–31%** |
| 谁承担 | 平台促销逻辑（买家端额外降），卖家按折后价结算部分 |
| 叠加 | 在**卖家折扣之后**再叠算（折上折） |
| 排名加成 | ≥50%商品设 ≥5% 俱乐部折扣 → 这些商品排名提升 |
| 操作 | 「价格与折扣」→ WB 俱乐部折扣标签 / XLSX 批量 / API（>100万商品） |

**示例（官方）：** 商品 1000₽，卖家折扣 20% → 800₽；俱乐部折扣 10% × 800 = 80₽ → 最终到手 720₽

## 四、怎么区分「到底谁出的折扣」（一眼判断表）

| 折扣类型 | 谁出钱 | 前端价 vs 定价 | 买家到款按什么算 | 你能控制 |
|---------|:---:|:---:|:---:|:---:|
| **WB 折扣** | **WB** | 定价 - WB补贴 | **按定价（不计补贴）** | 仅加成部分(+10%,靠投广告) |
| WB 俱乐部折扣 | 平台促销逻辑 | 定价 - 卖家让利 - 俱乐部折 | 按折后价 | 设 3-31%+是否参与 |
| 卖家自设促销折扣 | **卖家** | 定价 - 你让多少 | 按折后价 | 全控制 |
| 自动促销深度 | **卖家**（最大深度=最亏） | 你让多少降多少 | 按折后价 | 选深度、设最低价、锁价 |

**记忆口诀：**
- 「**买家看到更便宜，但你的到款没变**」→ **WB 折扣（平台补贴）**——这是好事，别慌
- 「**你主动降价，到款也变少**」→ **卖家让利**——这是你的成本，要控

## 五、对广告投放的判断影响（本店实测教训，2026-09）

**场景**：全店出单下降，某品拉了竞价（1900→2100）。

**错误判断**：以为是广告投错了 / 加价导致补贴下降。

**正确结论（从官方机制推得）：**
1. **拉竞价 ≠ 影响 WB 折扣基础部分**——两套独立系统，时间重合是巧合
2. **但广告投入的节奏/占比会影响加成部分（最多10%）**——断投/突击投会掉加成，连续投才稳
3. **全店出单降的主因 = WB 补贴收缩 → 买家到手价变贵**，而非广告
4. **加价确实能保住位置**（某品靠 +200 没掉）——加价是有效的，只是方向在"保位"不在"救转化"

**诊断动作**：
- 先确认「前端价涨了」还是「你提了标价」（决定是平台侧还是你控制侧）
- 看数据来源：事件日历=全量（自然+广告混合）；广告统计=单口径广告。**全店展示都涨但你没开全店自动 → 是自然流量季节放大，不是你加价引起**
- 等 WB 补贴企稳，价格修复后，季节增量就是纯转化机会

## 六、自检清单

```
□ 前端价 vs 我定价，差额是谁出的？（WB折扣=平台出，我让利=我出）
□ 我的品在不在「可提升WB折扣」的类目里？（在的话广告投入=在省补贴）
□ 广告是连续投还是断投？加成掉了没有？
□ 促销是不是卡在「最大」深度？（=我在不知情地让利）
□ 数据看的是全量还是广告单口径？
```

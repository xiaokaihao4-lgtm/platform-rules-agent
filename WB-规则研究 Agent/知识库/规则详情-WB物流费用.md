# WB 物流费用完整计算框架

> 整理日期：2026-09-22 ｜ 来源：WB 帮助中心俄文原文 + 官方新闻
> 主要出处：《Типы логистики и расчёт стоимости》(logistics-types-and-cost-calculation)、《Приёмка, хранение и логистика склада》
> ⚠️ 费率数字已全部从官网页面逐档验证（2026-09-22 复核），但 WB 费率随时调整，以后台「Поставки и заказы → Тарифы」实时数据为准。

---

## 一、第一步：算体积（所有费用的基础）

**体积（升）= 长 × 宽 × 高（cm）÷ 1000**

- 按**含包装**的最大外廓尺寸量（按商品最大点，不是中心点）
- 可压缩商品（软包、折叠类）**按展开状态**计算
- 你的品类提醒：折叠桌椅/餐椅/滑板车这类，**包装尺寸决定一切**——优化包装盒一个档位差价就是几卢布/单
- 档位跳跃陷阱：0.400→0.401 升，费用直接从 26₽ 跳到 29₽

---

## 二、正向物流费（订单出库配送，2025-09-15 起生效费率）

### ≤1 升：按体积档位收一口价

| 体积（升） | 费用（₽/件） |
|---|:---:|
| 0.001 ~ 0.200 | **23** |
| 0.201 ~ 0.400 | **26** |
| 0.401 ~ 0.600 | **29** |
| 0.601 ~ 0.800 | **30** |
| 0.801 ~ 1.000 | **32** |

> 官方例子：0.450 升和 0.550 升同档，都收 29₽。

### >1 升：首升 + 每加升

```
物流费 = 46 ₽（首升） + 14 ₽ × 额外升数
例：1.8 升 → 46 + 0.8×14 = 57.2 ₽
```

### 再乘两个系数

```
实际物流费 = 基础费 × 仓库配送系数 × 本地化指数(ИЛ)
```

- **仓库系数**：每个仓不同（如 Софрино СГТ = 0.95），发热门仓系数高
- **本地化指数**：每周一按前 13 周订单重新算；`—` = 不加成
- **СГТ/КГТ+/КБТ 大件不乘 ИЛ**（公式只有仓库系数）
- **费率锁定**：选定发货日期后，物流费率固定 **60 天**（服装/鞋/童装/内衣类目 **90 天**），期间即使官方调价也不变；退货转到其他仓也不变

---

## 三、大件（СГТ/КГТ+）专线

```
(46₽ 首升 + 14₽×额外升) × 仓库配送系数
下限 1000 ₽ / 上限 3000 ₽（每件）
```

- 不乘本地化指数
- 例：算出来 800₽ → 照样收 1000₽；算出来 4000₽ → 只收 3000₽

---

## 四、入库费（приёмка，随入库日期浮动）

| 包装方式 | 公式 |
|---|---|
| 箱装（короба） | **1.7 ₽/升 × 仓库入库系数 × 总升数** |
| 整托（монопаллеты） | **500 ₽/托 × 仓库入库系数 × 托数** |

- 系数在排期日历里锁定；到货允许 ±24 小时误差不变价
- 货量比计划**多 100 件以上且超 10%** → 入库系数 +1
- 仓库空闲日入库可能**免费**；爆仓日变贵
- 实际以入库后按真实尺寸结算为准

---

## 五、仓储费（хранение，超免费期后按天）

- **箱装**：(首升价 + 额外升价×升数) × 仓库仓储系数 ÷ 按天
- **整托**：**23 ₽/天 × 仓库仓储系数**
- 系数下降 → 全仓所有商品同步降
- 查询：周报「仓储费」+ 报表「Отчёт по номенклатурам」
- 你的风险品类：折叠桌椅/蹦床/推车体积大，**滞销 = 仓储费持续放血**——动销差的尽早清仓或转 FBS

---

## 六、逆向物流（退货/拒收）——最容易踩的坑

### 买家拒收/退回

| 场景 | 费用 |
|---|---|
| 退回仓库（отказ/возврат） | **只收基础物流费**（不另加） |
| 退到买家附近取货点（ПВЗ） | 体积费×仓库系数 **+ 155 ₽** |
| 按地址退（до адреса） | 体积费×仓库系数 **+ 255 ₽** |
| 大件 СГТ 退回 | 体积费×仓库系数 **+ 1000 ₽** |
| 无法识别商品（未贴码等） | **255 ₽/件** |

> 固定附加费在体积费×系数**之后**再加（例：76.78₽ + 155 = 231.78₽）
> 买家退回仓库的运费**不乘本地化指数**。

### FBS（平台卖家）模式退货（2026-08-07 降价后）

```
退到 ПВЗ：25 ₽ 首升 + 4 ₽ × 额外升
```

### 退货无人取走的罚则（退到 ПВЗ 等你的场合）

| 天数 | 费用 |
|---|---|
| 前 3 天（含到货日） | 免费 |
| 第 4~7 天 | **10 ₽/件/天** |
| 第 8 天起 | 转销毁流程，**44 ₽/件**（处置服务另计） |

## 七、2026 年三项变化（记住这些）

1. **2026-07-13 取消 ИРП**（附加系数）
2. **2026-08-15 取消本地化指数加成**（部分场景不再乘 ИЛ）
3. **2026-08-07 FBS 退货运费大降**（降到 25₽+4₽/升）

## 八、实战速查（你的品类）

| 商品 | 典型包装体积 | 单件物流费估算 |
|---|---|---|
| 配件（管子支架/把手） | 0.1~0.3 升 | 23~26 ₽ |
| 餐椅/成长椅 | 0.4~0.8 升 | 29~30 ₽ |
| 儿童桌/折叠桌椅 | 1~3 升 | 46 + 14×升数 |
| 蹦床/推车/自行车 | >3 升或 СГТ | 88~3000 ₽ 封顶 |

**降本三杠杆（按你可控度排）：**
1. **包装瘦身**——挤进低一档费率（0.41→0.39 升省 3₽/件×日单量）
2. **选发货仓**——入库/物流/仓储三个系数一起看，别只挑快的
3. **控库存天数**——大件滞销的仓储费会吃掉全部毛利

## 九、查询入口（后台）

```
Поставки и заказы → Тарифы → Тарифы складов
  ├─ 物流/入库/仓储系数：按仓库、按日期查（排期日历直接显示）
  └─ «Тарифы на остаток»：当前在仓商品的仓储费率
周报（отчёт о реализации）→ 物流费/仓储费/退货费实际发生额
Отчёт по номенклатурам → 按 SKU 查明细
```

## 一、官方定位

**官方原话：** "内部研究显示，买家更倾向购买有富媒体内容的商品"——视频和富媒体是**直接拉转化的**，不是装饰。

## 二、视频相关的 4 个工具（按成本排序）

### 1️⃣ 普通商品视频（免费）

- 每张卡片可加 **1 个视频**，买家点开卡片才能看
- 位置：图片轮播里

### 2️⃣ 视频封面（Видеообложка，免费）

**用照片自动生成视频**，最省事的视频方案：

| 效果 | 需要什么 |
|------|---------|
| 幻灯片 (слайд-шоу) | 2-5 张照片 |
| 信息图动画 (инфографика) | 1 张带标注的照片 |
| AI 视频 / 动图 (ИИ-видео / живые фото) | 1 张照片（用 Jam 的 Фотостудия 限额） |

**关键机制：**
- 卡片有 **≥2 张照片就自动生成**视频封面（编辑卡片 → «Что улучшить в карточке?» → 视频封面 → 查看）
- 卡片里**只能存 1 个视频封面**，位置在主图后**第二位**——黄金位置
- 生成的视频**订阅到期后仍保留**在卡片里

**⚠️ 配合自动播放才有意义**：视频封面 + 自动播放 = 视频占据图片轮播第一位，在**目录页和搜索页直接自动播放**——官方明说"比其他卡片更醒目"。

### 3️⃣ 视频自动播放（Автозапуск，付费）

| | Jam 订阅 | 费率构造器 |
|---|---------|---------|
| 生效范围 | **所有位置**（卡片+目录+搜索） | 自选：仅卡片 或 仅目录/搜索 |
| 数量 | 标准 10 张 / 进阶 50 张 | **无限制** |
| 费用 | 月费内含 | 销售佣金 % |

**切换规则**：同一卡片只能用一种方式开自动播放；切换时先关 Jam 再开构造器（或反之）。

**视频参数要求（不达标无法开通）：** 见下方尺寸表。

### 4️⃣ Rich Content（Рич-контент，免费）

卡片里 «О товаре» 区域的图文混排块，**最多 10 个模块**，可含文字/图标/图片/视频。

**AI 生成**：WB 神经网络可基于卡片信息自动生成 10 模块。
- 免费额度 20 次/月
- Jam 标准 50/月、进阶 70/月
- 无限选项（Показ и генерация без ограничений）可解除限制

**批量复制**：开通无限选项后一次可复制到 **40 张卡片**（文字图片可复制，视频要手动）。复制后各卡片独立，改一张不影响其他。

**发布红线（违规审核不过）：**
- ❌ 水印
- ❌ 价格/折扣文字、联系方式、二维码、外链
- ❌ 行动号召（"快下单""联系经理""点赞收藏"）
- ❌ 营销词（"хит""超值""划算价"）
- ❌ 引用买家评论
- ❌ 模糊/居家背景照片（地毯、家具、阴影）
- ❌ 3D 图当实拍图用
- ❌ 酒精烟草、18+ 未打码、暴力仇恨内容

**审核流程**：发布 → модерация → 通过后 5 分钟内可见。不过审的模块标红，改完重发即可。

**位置**：买家端显示在评分/评论/买家照片之后，不占用原描述位置。

## 三、📐 完整尺寸要求表（8/28 官方版）

### 商品照片

| 项目 | 要求 |
|------|------|
| **分辨率** | **最低 700×900 px**（3:4 竖版） |
| 格式 | JPG / PNG / WEBP |
| 压缩质量 | ≥65% |
| 文件大小 | ≤10 MB |
| 数量 | **最多 30 张，最少 2 张**（无图不进搜索） |

**影响卡片评分的照片因素：**
- 主图裁边/商品不完整 → 降分
- 背景杂乱/渐变背景 → 降分
- 营销文字（季节价/限时/清仓/厂家价等）→ 无论字号都降分
- 商品倾斜、多品一图、带包装 → 降分
- 水印 → 降分
- 高饱和荧光色信息图 → 降分

**无障碍配色建议**：图上文字对比度 ≥4.5:1（小字）/ 3:1（大字）；避开红绿、蓝紫等色盲混淆组合；背景禁渐变。

**审核**：照片全部过审。不合规 → 铃铛通知 → **72 小时内修改，否则卡片被锁**。待优化照片在编辑页有橙色边框提示。

### 商品视频（卡片内）

| 项目 | 要求 |
|------|------|
| **宽高比** | **3:4 竖版** |
| **分辨率** | **810×1080 px** |
| PAR | 1 |
| 格式 | MP4 / MOV |

### Rich Content 视频

| 项目 | 要求 |
|------|------|
| **方向** | **横屏 16:9**（跟商品视频相反！） |
| 格式 | MP4 / MOV |
| 文件大小 | ≤100 MB |

### Rich Content 图片

| 用途 | 分辨率 |
|------|--------|
| 封面图 | 800×500（会被裁边，主体放中间） |
| 横版组件 | 800×500 |
| 方形组件 | 700×700 |
| 竖版组件 | 700×900 |

格式 JPG/PNG，≤5 MB。

### ⚡ 速查表

```
主图/商品图：700×900 起（推荐拍 1500×2000），3:4 竖版
商品视频：  810×1080，3:4 竖版 ← 注意是竖的
富媒体视频：16:9 横版，≤100MB  ← 这个是横的
富媒体图：  800×500 / 700×700 / 700×900
照片数量：  每卡最多 30 张，最少 2 张
```

**最容易搞混**：商品视频竖版 3:4，富媒体视频横版 16:9——拍之前想好放哪里。

## 四、官方 5 步优化流程（改善照片视频，7/27 版）

```
步骤 1：看官方视频教程 + 读图片规则
步骤 2：按「卡片质量分」筛选要优化的卡片（后台直接给优化清单）
步骤 3：按官方拍摄规范重拍
   ├─ 物件图 (предметная)：中性背景、≥700×900、居中
   └─ 模特图 (модельная)：不遮挡产品、主图完整展示、可内嵌细节图
步骤 4：用免费工具加工
   ├─ Фоторедактор：拼图/换背景/裁剪/加文字图标
   ├─ Фотостудия：AI 生成产品图（Jam 限额）
   ├─ Видеообложки：照片生成视频
   └─ 3D-модель：家居品类可用 AR 查看
步骤 5：（可选付费）自动播放 + 照片标记 + 卖家推荐模块
```

## 五、官方优化卡片总流程（Как оптимизировать，7/27 版）

1. **收集搜索词**：Яндекс.Wordstat / Google Trends / «Поисковые запросы на WB» / «Сравнение карточек»
2. **标题**：只放精准关键词，禁同义词堆砌、禁重复、禁不相干词
3. **描述**：关键词自然融入、突出特点和好处、检查错别字；Jam/构造器可用 AI 生成描述
4. **属性**：全部填满；有下拉提示的优先从列表选（影响筛选器流量）
5. **附加工具**：Rich Content / 照片标记（Jam 专属）/ 卖家推荐（构造器或 Jam 进阶）/ Ягодки 返现
6. **持续监控排名**，掉了就优化内容——搜索结果是动态的

## 六、落地建议（结合本店品类：推车/滑板车/折叠桌椅）

品类特点：功能型产品、使用场景是卖点、体积大需要展示折叠过程。

| 优先级 | 动作 | 理由 |
|:---:|------|------|
| 🔴 P0 | **主力 SKU 全部加视频封面 + 开自动播放** | 有 Jam 进阶额度 50 张；目录页自动播放 = 免费流量抢眼，对功能型产品效果最好 |
| 🔴 P0 | 视频内容拍"**折叠/展开过程 + 使用场景**" | 3:4 竖屏 810×1080；推车一键折叠、桌椅收纳过程是最强卖点 |
| 🟡 P1 | Rich Content 加"**尺寸对比图 + 场景图**" | 折叠桌椅买家最关心收起来多大、放后备箱行不行；10 模块里 1 封面+4-5 模块就够 |
| 🟡 P1 | 用 A/B 测试选主图（Jam 高级含 10 次/月） | 主图 CTR 直接影响广告质量分 |
| 🟢 P2 | 配件店卡片挂"照片标记" | 主图里标记兼容的其他商品，带动配件连带（Jam 专属功能） |

**反直觉提醒**：别急着买"照片质量提升"付费选项——免费的照片编辑器 + 照片工作室已经够用，先把免费的吃干净再考虑付费。

## 七、一次拍摄全覆盖方案

1. **主拍 3:4 竖版**（2000×2666 px 或至少 1500×2000）：
   - 主图：白底展开全貌
   - 图 2-5：折叠过程（推车一键收车动作单独一张）
   - 图 6-8：使用场景（商场、公园、后备箱）
2. **视频竖拍 3:4（810×1080 输出）**：15-30 秒，内容=展开→使用→折叠收纳，配自动播放当视频封面
3. **横版素材另拍 16:9**：只在要上富媒体时才需要，优先级低

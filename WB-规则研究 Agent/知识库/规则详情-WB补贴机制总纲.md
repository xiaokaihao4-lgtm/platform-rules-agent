## 零、最核心的一句话（先记住这个）

**买家看到的"便宜"到底谁出钱**，决定它是"平台的补贴"（你要抓住）还是"你的让利"（你要控制）。识别口诀：

```
「买家看到更便宜，但你的到款没变」→ WB 平台补贴（抓住）
「你主动降价，到款也变少」→ 你的让利（要控成本）
「买家折价，你按折后结算」→ 混合/卖家侧促销（看占比）
```

## 一、买家最终到手价的完整公式（所有折扣叠加顺序）

WB 帮助中心《如何设置价格与折扣》给出买家看到价的形成因素：

```
买家看到的价格 = 卖家定价
  - 卖家折扣(你设的)
  - WB 折扣(Скидка WB，平台出)
  - WB 俱乐部折扣(3-31%)
  - WB 钱包折扣(支付时按钱包等级)
  - 卖家自有促销/优惠码(若开)
  - 忠诚折扣(若开)
  - (按参与的活动再叠)
```

**⚠️ 关键：买家看到的价、你收到的款、平台出的钱——三者不是一回事，必须分开看。** 这是理解补贴的全部关键。

## 二、6 种折扣的"谁出钱"判定表（核心）

| # | 折扣类型 | 谁出钱 | 到款怎么算 | 你能控制 | 官方原文 |
|---|---------|:---:|-----------|:---:|------|
| 1 | **WB 折扣（Скидка WB / 旧名СПП）** | **WB 出** | **按你定价（不计Wb折扣）** | 仅加成(+10%靠投广告) | A-338 |
| 2 | **WB 俱乐部折扣（Скидка WB Клуба）** | 平台促销逻辑 | 折后结算部分 | 设3-31%、是否参与 | A-337 |
| 3 | **WB 钱包折扣** | WB（按买家钱包等级） | 平台出 | ✗ 你管不了 | A-55 |
| 4 | 卖家自己设的促销折扣 | **你出** | 折后结算 | 全控制 | A-55 |
| 5 | 卖家自有促销/自有活动 | **你出**（+1%佣金） | 折后结算 | 设折扣/区域/日期 | A-1779 |
| 6 | 卖家优惠码(Pромокод) | **你出** | 折后结算 | 设3-50%、一次性/多次 | A-1731 |

**记忆锚点：**
- **WB 折扣（第1种）**是你这次餐椅问题的主角——**平台自费补贴，你按定价收款，广告连续投可再拿最多+10%加成**
- **卖家相关折扣（4/5/6）**才是"你让利"，才是要控的

## 三、重点：WB 折扣（Скидка WB）完整机制

### 3.1 定义（官方原文）
> WB 折扣 = 平台**自掏腰包**给买家的额外折扣。买家看到的价格已含此折扣。
> **你收到的货款按「你的折前价 + 你设的卖家折扣」算，不计 WB 折扣部分。** 力度 WB 自己定，会变。

### 3.2 变化规律
| 影响因素 | 细节 |
|---------|------|
| **基础部分** | WB 自己定，会主动涨/缩（你控制不了，但影响全店到手价） |
| **广告加成** | 最多 **+10%**，按**最近14天广告/推广花费占比**算，**每天更新** |
| 加成规则 | 连续每天小额投 > 突击一天投；**促销奖金不计入** |
| 加成作用域 | 作用于**该品类所有商品**（不只你投的） |
| 加成类目 | 仅特定类目开放（含儿童用品、体育用品等，会扩展） |
| 查看 | 推广后台活动页有「额外 WB 折扣」widget |
| 惩罚 | 自买东西=人工销量 → WB折扣对全店停30天 |

### 3.3 开关
- 价格与折扣 → 「Действия」→「Настроить скидку WB」→ 全店或按SKU（XLSX模板）
- 改一次最多每24小时一次
- **关闭WB折扣 ≠ 直接降排名**，但会让买家到手价变贵 → 间接收转化和排名

### 3.4 对广告的判断意义（本店实测）
```
WB补贴收缩 → 买家到手价变贵 → 全店转化下降（非广告问题）
广告连续投 → 拿加成 → 补贴高 → 到手价低 → 转化好
⇒ 别在补贴收缩期砍广告/停广告，维持连续稳定投入更稳
```

## 四、WB 俱乐部折扣（Скидка WB Клуба）

### 4.1 基本规则
| 项目 | 说明 |
|------|------|
| 力度 | 可设 **3%–31%** |
| 叠加 | 在**卖家折扣之后**叠算（折上折），例：20%卖家折后800 → 俱乐部10%×800=80 → 到手720 |
| 谁承担 | 平台促销逻辑（买家端额外降） |
| 谁可用 | 买家付 WB Клуб 订阅费后享有 |

### 4.2 排名加成（重要，可直接操作）
- **≥50%商品(按卡片数)设 ≥5% 俱乐部折扣 → 这些商品加 2% 排名系数**
- 参与有排名加成的促销活动 + 俱乐部折扣 → **两个加成累加**
- 想进俱乐部精选位(подарки/промокоды)：设≥5%覆盖50% 或 ≥10%覆盖10%，总覆盖60%

### 4.3 效果数据（官方研究）
- 俱乐部买家：下单数+8%（2024研究）~ 各品类 1.6x–9x 于普通买家，LTV更高、客单高67%
- 设折扣越高，单量/件数增长越大：3%→单量+5%，15%→+13%，31%→+18%

---

## 五、WB 钱包折扣（Скидка WB Кошелька）
- 买家按钱包等级（WB Клуб 会员加成）在支付时享受不同折扣
- **平台出**，你管不了，但它是"买家到手价"的一部分
- 俱乐部会员用钱包支付有额外折扣

## 六、促销/自动促销体系（卖家可选参与）

> ⚠️ **来源标注（2026-09-22 核查）**：本篇官方原文属**后台内嵌帮助**（「Товары и цены → 对应板块 → 右下角"?"圆圈」），官网 material 页只回「Статья доступна только продавцам」不吐正文。本节内容为多源交叉整理，细节以后台内嵌帮助为准。

### 6.1 促销类型
| 类型 | 谁决定 | 说明 |
|------|:---:|------|
| 普通促销 | 你手动加 | 价格必须≤促销价或降价后进 |
| 自动促销 | 系统自动加 | 自动打折，你可排除/设最低价/锁 |
| 2种都限制 | — | **上架≤15天的新品不参与任何促销** |

### 6.2 促销的排名效果（A-323）
- 参与促销 = 排名加成（普通+自动都算）
- **参与越多商品 → 排名加成越大**
- 促销位：搜索/目录靠前 + 红色价格标 + 首页横幅 + "促销"筛选项

### 6.3 自动促销的控制（重要，防"让利陷阱"）
| 工具 | 作用 |
|------|------|
| **最低价格** | 自动促销不得低于此价（除非你主动降） |
| **折扣锁定** | 阻止自动折扣应用到指定商品 |
| 排除商品 | 从促销剔除 |

**⚠️ 默认「最大」折扣深度**（A-967）：不调 = 以最深折扣跑 = 利润最小。**必须查这个**。

### 6.4 价格审查（Карантин）（A-34）
- 降价/增折扣超阈值→进隔离（防手误少打0）
- 默认 33.3%（1.5倍），可设 33.3%-47.5%
- 隔离期商品按**原价**卖；30天自动解除；促销/自动促销降价不触发
- 想降>50%：不能一次降，分步降

## 七、卖家自有促销工具（你控制、你让利）

### 7.1 自有区域促销（Собственные акции，A-1779）
- 仅俄区，**莫斯科除外**（测试期）
- 折扣 **3%-50%**，3-14天，可同时5个，选1-5个区域
- 成本：+**1% 佣金**对促销卖出商品
- 起点需提前24h；结束仍需3-72h生效

### 7.2 忠诚折扣（Скидка лояльности，A-1622）
- 按买家365天在你的店累计成交额设档
- 门槛 1000-100000₽，折扣 3%-50%
- 成本：仅对带折扣成交单收佣金
- 90天最低期限

### 7.3 卖家优惠码（Промокоды，A-1731）
- 折扣 3%-50%，一次性/多次，1-180天
- 同时最多 500 个活动，10万商品可参与
- **不叠加**：买家已有WB优惠码则你的不生效；与忠诚折扣自动取优惠大的
- 报告有「ID优惠码」「优惠码折扣%」两列

## 八、价格指数（Индекс цен，A-78）+ 价格更新

> ⚠️ **来源标注（2026-09-22 核查）**：A-78《Индекс цен》（更新 08.06.2026）与 A-266《Окно управления ценой товара》（更新 18.05.2026）**均为后台内嵌帮助**。已用官方文章 API 取证：其 `contentUrl` 正文 JSON 仅 1.6KB，内容就是一句「请到 商品与价格→价格指数 板块点右下角"?"查看」——**正文未对外发布**。另实测该板块 URL `/prices-index` 对 kz 区账号直接跳回首页。本节为多源交叉整理，官方细则以后台内嵌帮助为准。

### 8.1 价格指数
- 对比你的价 vs WB/Ozon/DNS/Ситилинк/Lamoda 同行价
- 结果"Выйгодно(划算)"或"Дорого(贵)"
- **划算** → 卡片"好价"标 + 搜索额外推荐
- **贵** → 不处罚不降排，但无加成
- 仅俄区卖家、每天更新

### 8.2 改价更新
- 正常几分钟生效；有错进"变更历史"不生效
- 改价/改折扣可能导致从促销掉出（看"参与活动价"列）

## 九、一个动作：先查促销折扣深度（最容易被"默认最大"坑）

```
路径：促销日历 → 找到参与的活动 → 看折扣深度
或：价格与折扣 → 找到该商品 → 看促销状态

如果显示「Максимальная(最大)」而你不想打那么深 → 促销开始前5小时降档
```

**对你餐椅的意义**：如果你在自动促销里卡在「最大」深度,等于你**自己在让利** → 到手价更贵是"平台补贴降 + 你让利深"双因素 → 利润双重压缩。

## 十、对"全店出单下降"的标准诊断流程（固化）

```
1. 判断数据来源：事件日历=全量(自然+广告) / 推广统计=广告单口径
2. 确认"价格涨了"是哪种：前端价(补贴/平台) 还是 你提标价(你控制)
3. 前端价涨 + 你没改标价 → WB补贴收缩(平台侧) → 全店转化下降是结构性的
4. 别砍广告——连续投在拿WB折扣加成，砍了=到手价更贵
5. 查你的促销折扣深度是否卡在最大（=你额外让自己更贵）
6. 等WB补贴企稳，价格修复后，季节增量流量就是纯机会
```

## 十一、补贴收缩期应对决策（2026-09-22 定版·餐椅案例提炼）

**场景**：销量下滑、流量/点击没变、转化降、WB 补贴（前端折扣）在降。

### 第一原则：别降卖家售价

降卖家价 = 用自己的毛利去填平台的坑，且有三个不可逆后果：
1. 买家有价格记忆，**降价容易提价难**（提价=二次涨价观感，转化再挨一刀）
2. 价格指数基准、自动促销锁价基准全部跟变
3. 补贴是平台每天在变的，随时可能回来——你为暂时性波动做了永久性定价决策

**判别口诀**：买家看到更便宜但你到款没变 = 平台出钱（别动）；你主动降价到款也少 = 你让利（要控）。

### 动手前 10 分钟验证（商品对比工具）

```
Сравнение карточек → 自己 vs 同价竞品 → 周期「周」按日看「买家中位价」
├─ 竞品中位价也涨了 → 全品类补贴收缩，大家都贵 → 不动，等（3-5天观察窗）
└─ 只有你涨了      → 被单独降补/对手抢加成 → 干预（用可逆杠杆）
再查两处：推广后台「额外WB折扣」widget（广告加成是否掉了、14天连续投入是否断了）
        ＋ 价格指数列（是否从「划算」滑向「贵」→ 丢好价牌和推广）
```

### 触发线（量化了再动）

```
每天真实损失 = 日销减少件数 × 单件毛利
让利成本   = 客单价 × 让利率 × 预计恢复前总件数
损失 > 成本 → 干预划算；否则 → 等补贴回来更划算
```

### 干预杠杆顺序（从可逆到不可逆）

| 顺位 | 手段 | 性质 |
|:---:|------|------|
| 1 | 优惠码/自有促销让 3-5% | 临时弹簧，随时关，不动定价基准 |
| 2 | 俱乐部折扣提到 ≥5% | 换 2% 排名系数+俱乐部流量 |
| 3 | 保持广告连续投入 | 平台出钱帮你出折扣加成（最多+10%） |
| ❌ 最后 | 降卖家价 | 真降也**只补一半缺口**，记好原锚点方便回提 |

### 反例（2026-09 餐椅案）

10 号占比 4% → 拉竞价 1900→2100 保排名 → 同期补贴 31%→18% → 出单掉一半。
诊断：加价只买到排名没买到转化，钱花在了对抗价格问题上——方向反了。
正确动作：竞价可降回、广告别断投（保加成）、到手价用优惠码处理、等补贴企稳。

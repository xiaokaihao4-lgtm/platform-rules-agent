## 🔥 6月重要更新（9篇）

### 1. 评论返现（Кешбэк за отзывы и вайбы）⭐ 新功能
**更新日期**: 03.07.2026

新工具：激励买家留下**扩展评论（≥200字）+ Wibes竖屏视频**，卖家给返现。

**运作机制：**
- 卖家创建活动 → 选商品 → 设返现比例(25%-50%) + 目标评论数(最低5条)
- 买家成交后收到推送 → 5天内留扩展评论+发Wibes视频
- 评论通过审核 + 14天不退货不删评 → 买家收到" ягодки"（莓果币）到WB钱包
- 1 ягодка = 1 ₽，365天有效，可买WB上任何商品

**费用：**
- 返现金额从卖家余额扣
- 额外收10% WB服务费（含增值税）
- 例：商品1000₽，返现25% → 买家得250 ягодок，卖家扣250₽+25₽服务费=275₽

**限制：**
- ⚠️ **只有俄罗斯卖家可以创建**（跨境卖家暂不可用）
- 18+商品不能参加
- 已参加"积分换评论"的商品不能同时参加这个
- 买家4或5星才能拿返现
- 同一商品多次购买只返1次

**对跨境卖家的影响**: 目前不能直接用。但如果未来开放给跨境卖家，这是比"积分换评论"更强的工具——因为要求视频评测，对转化率提升更大。持续关注开放动态。

### 2. 仓库存储费计算（Хранение товаров на складе）⭐
**更新日期**: 06.08.2026（最新！）

**计费公式：**
```
箱装/单片托盘 = 0.08₽/天 × 升数 × 仓库系数
单托盘 = 25₽/天 × 托盘数 × 仓库系数
```

**关键规则：**
- 创建供货时，存储和物流费率**锁定60天或90天**（按品类）
- 锁定期结束后，按"余货费率"计费（通常更贵）
- 各仓库有不同系数（如沃罗涅日仓库系数150% → 0.08×1.5=0.12₽/升/天）

**FBS特殊规则：**
- FBS模式下商品存在卖家自己仓库，不收WB存储费
- **但**：如果CГT（超大件）提前送到WB仓库 → 在指定发货日之前收 **1₽/升/天，最低100₽**
- FBS退货的商品如果退回WB仓库 → 按余货存储费率收

**查看费用路径：**
- 供货与订单 → 费率 → 仓库费率 → 供货费率标签
- 分析 → 报告 → 存储费报告
- 首页余额组件 → 收支标签

**对跨境卖家的影响**: FBS模式本身不收存储费，但要注意：①CГT提前送货会被收费 ②FBS退货退到WB仓库会按余货费率收费。定期检查"存储费报告"确认没有意外扣费。

### 6. AI助手聊天（Сервис «Помощник»: ИИ-чат）⭐
**更新日期**: 14.07.2026

WB官方AI助手，三个功能：

| 功能 | 说明 | Jam订阅要求 |
|------|------|-----------|
| AI聊天 | 自由提问商品数据/平台操作 | 需Jam订阅 |
| 数据请求 | 查商品销量/订单/退货/搜索排名等 | 有Jam无限制，无Jam每天1次 |
| 监控报告 | 定时自动推送商品指标 | 有Jam最多10个，无Jam1个 |

**可查数据：**
- 订单/成交/取消数
- 买家实付价格（含折扣）
- 促销参与情况
- 库存和供货
- **Top-5搜索词**（需Jam）
- **搜索平均排名**（需Jam）

**对跨境卖家的影响**: 你有Jam高级版，这个AI助手相当于免费的数据分析员。特别是**搜索排名监控**功能——可以每天自动推送搜索排名变化，比手动去推广统计翻数据方便很多。路径：WB Partners App或网页版 → Помощник。

### 8. WB快递物流新计算（«Курьером WB»: новый расчёт логистики）⭐
**更新日期**: 11.06.2026

**DBW模式（WB快递送货）物流费新算法：**

```
СГT（超大件）: 首升46₽ + 续升10₽/升，最低1000₽，最高3000₽
МГT（小件）: 首升46₽ + 续升22₽/升，最低500₽，最高1500₽
```

退货按同样费率收逆向物流费。

**对跨境卖家的影响**: 你是FBS模式（哈萨克斯坦→俄罗斯），DBW是另一种模式（WB派快递从卖家仓库取货直接送货）。目前DBW主要对СГT开放，城市有限。如果你在莫斯科/圣彼得堡有仓库且卖大件（如跑步机），DBW可以扩展配送方式。小件МГT目前只在莫斯科和圣彼得堡测试。

### 9. 评论积分新逻辑（Баллы за отзывы: обновлённая логика）⭐
**更新日期**: 14.07.2026

"积分换评论"工具全面更新，比之前的规则更完善。

**核心机制：**
- 卖家设活动 → 选商品 → 设积分数量 + 目标评论数 + 预算
- 商品上出现"100 Б за отзыв"标签 → 有标签的商品**在搜索结果中获得额外推广加成**
- 买家成交后5天内留评 → 通过审核 → 15天后（确认不退货不删评）→ 积分到账
- 1积分=1莓果币=1₽，365天有效

**两种受众选择：**
| 选项 | 说明 | 余额要求 |
|------|------|---------|
| 潜在+实际买家 | 先向已购买家收评，不够再向新买家展示标签 | 预算的30% |
| 仅潜在买家 | 标签立即展示给所有新买家 | 预算的20% |

**不积分的情况：**
- 退货或删评
- "空评论"（只有评分，文字<10字符）
- 评论内容与评分矛盾（正评但低分）
- 违反WB规则的评论

**不能同时参加"评论返现"和"积分换评论"。**

**对跨境卖家的影响**: 这个你已经在用。新逻辑的关键变化：①标签商品有搜索加成 ②余额要求更明确（20%/30%） ③推荐至少跑21天。如果你有评论少的弱色SKU，用这个工具加速积累评论。

# 规则详情-事件日历（Календарь событий）

> 来源：WB 官方帮助中心《Отчёт «Календарь событий»》（更新 03.09.2026）+《Частые вопросы по отчёту «Календарь событий»》（更新 07.09.2026）
> 整理日期：2026-09-09
> 状态：✅ 已验证（官方原文抓取）

---

## 一句话定义

**事件日历 = 每张商品卡片的一本"操作日记"**，把你在卡片上做过的所有动作（改价、改图、参加促销、开广告、被差评…）按时间轴记录下来，和销量/转化/排名曲线叠在一起看，让你知道**哪个动作导致了哪个结果**。

**入口**：分析 → 卖家分析 → 「事件日历」标签页

**权限**：Jam 订阅所有档位都可用（你有高级版，可用）

---

## 一、它能解决什么问题

| 用途 | 说明 |
|------|------|
| 追踪卡片变化 | 看某段时间你对卡片做过什么 |
| 控制卡片效率 | 哪个动作让指标变好/变差 |
| 自己加事件 | 平台不记录的（换包装、送赠品、找博主）也能标进去 |
| 研究历史 | 改动 → 指标变化的因果关系 |

## 二、三个入口

1. **主菜单**：分析 → 卖家分析 → 「事件日历」→ 看到所有卡片列表 → 点某张卡 → 新标签页打开它的日历
   - 排序：按名称 / 创建日期 / 最后修改日期
   - 筛选：按品类、品牌、货号、标签
2. **销售漏斗报告**：卖家分析 → 销售漏斗（与同期比较）→ 表格里选卡片 → 「事件日历」按钮
3. **商品卡片页**：商品与价格 → 商品卡片 → 点表格里的卡片 → 右侧迷你报告顶部有入口

> 每张卡片都有独立的日历（已删除的卡片除外）

## 三、页面构成

### 1. 商品信息区
- 卡片填充度评分 + 评价评分（近2年平均，新评价权重更高）
- WB 货号 + 卖家货号
- 评价评分不适用时显示「无评分」

### 2. 图表区（最多同时对比 5 个指标）

| 指标 | 说明 |
|------|------|
| 展示次数 | показы |
| 进入卡片 | перешли в карточку |
| CTR | 点击率 |
| 加入购物车 | положили в корзину |
| 加购转化率 | 加购数 ÷ 进入卡片数 × 100 |
| 下单件数 | заказали товаров |
| 下单转化率 | 订单数 ÷ 加购数 × 100 |
| 下单金额 | заказали на сумму |
| 成交件数 | выкупили товаров |
| 成交金额 | выкупили на сумму |
| 成交率 | процент выкупа |
| **平均排名** | 搜索位置算术平均（只算产生加购/点击的位置） |
| 评价评分 | рейтинг по отзывам |
| **买家价格** | 买家实付（含平台折扣+WB钱包折扣），**三条线**：最高/最低/中位 |
| 全部库存 | все остатки |

- 可按 **日 / 周 / 月** 切换
- 鼠标悬停显示当天发生的事件 + 与前一日对比
- 同一指标不能选两次；只看一个就把其他勾掉

### 3. 事件表格

按语义分组（卡片相关 / 促销相关 等）：
- ✅ 可隐藏/显示分组、调整组内顺序
- ❌ 不能跨组移动、不能自建分组

**事件时长**：1 天 ~ 1 年连续

**平台自动记录的事件类型：**

| 类型 | 具体内容 |
|------|---------|
| 卖家价格变更 | изменение цены продавца |
| 卡片操作 | 改标题 / 改描述 / 改图 / 改富媒体 / 合并拆分变体 |
| 参加促销 | 促销活动 + 自动促销 |
| 评价操作 | 「评价积分」活动、差评（1-3星）、置顶评价 |
| 照片标记 | 谁标了你 / 你标了谁 |
| **推广活动** | **WB Продвижение 广告活动启动**（← 最新加入，就是你截图那条横幅） |
| 我的事件 | 自建事件，最多 **10 种类型** |

**时间导航**：选中时段高亮蓝色；滚动可前后移 ±3 个月；箭头可到一年前/一年后；「回到所选时段」按钮复位。

**点彩色格子**可看事件详情。

### 4. 自建事件（重点功能）

点「创建事件」→ 选类型或新建类型 → 填日期 + 简短描述 → 创建。可编辑、可删除（**删除不可恢复**）。

**适合自建的事件**（WB 不记录的）：
- 换包装
- 买家赠品活动
- 博主投放 / 站外推广
- 供应商变更
- 任何你希望和销量对照的外部动作

### 5. 导出
「创建 Excel」→ 下载完整事件报告 + 指标图表。

## 四、数据口径（重要，别误读）

**计入：**
- ✅ 所有有物流动作的成功订单（下单→仓库分拣→配送/送达自提点）
- ✅ 所有成交（含后来退货的）
- ✅ 买家在分拣前取消、自提点/配送拒收、App 内退货、收货后退货、超期未取

**不计入：**
- ❌ 分拣前 1 小时内取消的订单
- ❌ 买家未付款而作废的订单
- ❌ 技术性取消

## 五、实战用法（结合本店）

### 用法 1：广告效果归因（最直接）

你之前纠结"广告投了到底有没有用"——现在可以直接看：
```
图表里勾选：下单件数 + 买家价格 + 平均排名
表格里看：「推广活动」事件（广告启动日期）
→ 广告启动那天起，下单曲线有没有抬起来？
```

### 用法 2：改价/改图的真实影响

```
改价 → 看价格曲线断崖那天 → 对比下单量、加购转化率
改主图 → 看 CTR 变化
```
**结论直接可验证，不用猜。**

### 用法 3：差评冲击评估

```
「评价操作」事件里能看到差评日期（1-3星）
→ 对比那几天转化率和成交率有没有掉
```

### 用法 4：外部动作对照

博主投放、换包装 → 自建事件标进去 → 一周后回看曲线，判断值不值。

### 用法 5：卡片横向对比

用「另一张卡片」按钮快速切换，对比同系列不同颜色的表现。

## 六、注意事项

- 报告只覆盖**有动销**的数据；买家价格显示 0 = 该期间无销售
- 自建事件类型上限 10 种，**删除不可恢复**
- 事件只能落在已有分组内，不能自建分组
- 数据更新有延迟（页面显示更新时间戳）

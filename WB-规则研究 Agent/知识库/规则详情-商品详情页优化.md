# 规则详情-商品详情页优化（搜索引擎排名优化）

> 来源：WB 帮助中心官方文章《如何优化商品详情页》（slug: `how-to-optimize-the-product-profile-ch`，A-2235）｜官方更新日期 **8/13/2026**｜本地整理 2026-09-22
> 本文全文译自官方中文原文（中文区本次实测可读，非二手转述）。

---

## 一、官方核心逻辑

```
买家搜索 → 算法挑"更符合搜索请求"的商品卡排前面
        → 排名越高 → 被购买机会越大
所以：商品卡的搜索排名 = 标题 + 描述 + 属性 对搜索词的匹配度
```

⚠️ 官方明确：搜索结果动态变化，**排名下降 → 检查内容 → 持续优化**（不是一次性工作）。

## 二、三步优化法（官方原文结构）

### Step 1 收集搜索请求（先知道买家搜什么）

| 工具 | 用途 |
|------|------|
| Yandex.Wordstat / Google.Trends | 站外热词研究 |
| WB「搜索请求」报告 | 你的卡在哪些词下有曝光（后台  Продвижение→Аналитика 或 Jam「Анализ внимания」） |
| WB「商品对比」报告 | 竞品靠哪些词出单（详见 [[规则详情-商品对比工具]]） |

### Step 2 优化三要素（标题/描述/属性）

**① 标题**
- 选**最贴切的关键词**放进标题
- ❌ 避免同义词堆砌（官方反例：Чехол для телефона смартфона——手机壳/智能手机壳同义词，删一个）
- ❌ 避免过多细节描述、使用建议、主观评价塞标题（那是描述该干的活）

**② 描述**
- 详细写：商品特点 + 对买家的价值
- 关键词**自然**融入文本（不是罗列）
- 检查拼写和语法错误
- 💡 JAM 订阅可用 **AI 描述生成**：按关键词+参数自动生成

**③ 属性（Характеристики）**
- **所有属性字段全部填**——买家筛选项找你的概率直接取决于此
- 属性下拉有带提示的选项时**选列表内的值**，不要手填自由文本（官方原话：提高通过筛选被找到的概率）

### Step 3 利用附加功能（放大曝光）

| 功能 | 作用 | 门槛 |
|------|------|------|
| 富媒体内容（Рич-контент） | 更详细生动的描述，转化增强 | —（详见 [[规则详情-详情页视频与富媒体优化]]） |
| 图片标记 | 让买家看到你**其他商品**（店内互链） | 仅 JAM 订阅 |
| 商品详情页推荐 | 扩大曝光面 | 仅 JAM「高级版」套餐 |

## 三、对你的品类的落地清单

1. **属性全量填写**是零成本最高杠杆——折叠桌椅/餐椅/滑板车的「折叠尺寸/承重/年龄/材质」下拉项逐个核对（买家筛选是儿童大件的主要流量入口）
2. 标题埋词用你的老流程（`wb-keyword-optimization`），但记住官方红线：**同义词、堆砌主观词会拉低相关性**
3. 排名下滑先跑「搜索请求」报告对比：词量掉了还是排位掉了 → 前者补词，后者优化内容/广告
4. 图片标记（Jam）适合你多 SKU 店铺（TEN 桌椅互挂、配件店挂主件）——流量内循环

## 四、与广告的关系（一句话）

推广位排名 = **有机权重 × 出价权重**（见 [[规则详情-推广体系]]）——详情页优化做的就是有机权重这个乘数，做不上去，出价再高也进不了前排。

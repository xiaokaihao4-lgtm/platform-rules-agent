### 要约 (合同) 核心条款 (23条)

1. 定义 (Определения)
2. 合同签订程序 (Порядок заключения договора)
3. 合同标的 (Предмет Договора)
4. 商品销售 (Продажа Товара)
5. 商品价格、报告与结算 (Цена Товара, отчётность и расчёты)
6. 卖家佣金及其他付款 (Вознаграждение и иные выплаты Продавца)
7. 合同变更 (Изменение Договора)
8. 最终条款 (Заключительные положения)
9. **门户使用规则** (Правила использования портала)
10. **商品包装与标记规则** (Правила упаковки и маркировки товара)
11. **商品验收与退货规则** (Правила приёмки и возврата товара)
12. **佣金计算规则 + FBS验收程序** (Правила расчёта вознаграждения)
13. **服务提供规则** (Правила оказания услуг)
14. **商品回购规则** (Правила выкупа товара)
15. **商品推广服务规则** (Правила оказания услуг по продвижению товаров)
16. **广告投放服务规则** (Правила оказания услуг по размещению рекламных материалов)
17. WB.MEDIA 申请表
19. 个人数据处理协议
20. 商品扣押 (Удержание товаров)
21. 车辆销售规则
22. 商品预订服务规则
23. 合同终止与账户关闭程序

## 🏭 适用于你的运营模式

### 当前店铺
- **Champ baby** - 婴幼儿用品（已登录确认）
- **TEN** - 多品类（滑板车、折叠桌椅）

### 你的销售模式
基于已配置的 FBS 模式，你需要重点掌握：

1. **FBS 订单处理流程** → 商品管理 → FBS 模式文章
2. **退换货规则** → 买家退货、有缺陷退货
3. **包装规范** → 不同品类包装要求（婴幼儿/桌椅/滑板车）
4. **佣金与费用** → 收费标准文章
5. **推广付费** → CPM自动/手动/CPC 模式

## ⚠️ 关键平台规则摘要 (来自 skill 已有知识)

### 广告推广核心规则
1. 切换出价模式 → 关键词全部清零，不可迁移
2. CPM 手动出价门槛极高，只有爆款品建议开
3. CPM 自动 = 搜索+推荐流量，CPC = 仅搜索
4. 同一品能否 CPM自动+CPC 双开需确认

### 数据导出规则
- 必须从统计列表页进入（不能直接 URL 导航已归档团单）
- 展开折叠行才准确
- 店铺切换用 `page.evaluate(el.click)` 才能触发
- 使用独立 Chrome Profile (`wb_chrome_profile`)

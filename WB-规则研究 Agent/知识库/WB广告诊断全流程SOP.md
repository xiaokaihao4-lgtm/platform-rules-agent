## 🔄 每日流程 (30分钟)

### 第一步：筛品 (5分钟)

打开 **广告统计** → 看两个指标：

| 找什么 | 阈值 | 标记 |
|------|:--:|:--:|
| 花费占比 | >50% | 🔴 优先处理 |
| 花费占比 | 20-50% | 🟡 |
| 花费占比 | <20% | 🟢 跳过 |
| 周订单环比 | 跌 >20% | 🔴 |

**挑一个🔴的。花费最高的那个。今天只搞它。**

---

### 第二步：定位漏斗层级 (10分钟)

打开这个品的 **销售漏斗**，看四层之间的落差：

```
展示 ──→ 点击 ──→ 加购 ──→ 下单
```

| 卡在哪 | 信号 | 跳转 |
|------|------|:--:|
| 展示→点击 | CTR 掉了 | → A路径 |
| 点击→加购 | 加购率掉了 | → B路径 |
| 加购→下单 | CVR 掉了 | → B路径 |

---

### A路径：CTR 出问题 → 搜索+推荐分开诊断

**搜索侧**：

进 **搜索请求(你的商品)** → 找到这个品的 SKU → 点左边箭头展开 → 看哪个词的展示次数高但排名低。

点词旁的图标 → 切到 **"按请求"选项卡** → 看"展示→访问转化率"是不是🟥。

🟥 → 换主图。Jam 高级版 A/B 测试(10次/月)，上传两个版本跑3-5天。

**推荐侧**：

下载 **扩展统计 XLSX** → 打开"目录统计"sheet → 看推荐位的 CTR。

推荐位 CTR 低 → 主图在推荐流太小不够突出，可能需要单独拍一版给推荐位用。

---

### B路径：加购/CVR 出问题

进 **搜索请求(你的商品)** → 展开品 → 找到核心词 → 点"按请求"。

| 🟥项 | 修法 | 见效 |
|------|------|:--:|
| 访问→加购转化率 | 调价5-10% / 加富媒体内容 | 1-3天 |
| 展示→下单转化率 | 先修上面这个 | — |
| 正品验证 | 找客服申请认证 | 1-2周 |

**补充检查**：打开活动内图表图标 → 看竞争出价和领导者出价 → 如果你的出价低于竞争出价，先提上去再判断。

---

### 第三步：做一个改动，记下来 (5分钟)

**今天只改一个变量。**

记录：日期 | 品SKU | 改了什么 | 改前数据 | 改后预期

3-5天后回来看。动了 → 有效，复制到其他品。没动 → 换一个变量。

## 📅 每周流程 (20分钟)

### 挖新词

打开 **WB搜索请求(全平台)** → 筛选你的类目 → 看本周热搜词。

找出：搜索量大 + 你的品还没覆盖 + 下单转化率高的词 → 加到下周广告里。

### 查推荐流

下载 **扩展统计 XLSX** → 对比搜索和推荐的 ROI：

| 发现 | 行动 |
|------|------|
| 推荐 ROI > 搜索 | 加大推荐预算，检查降低系数是否开启 |
| 推荐 ROI < 搜索 | CPM手动模式下降推荐位出价 |
| 推荐展示为0 | CPC模式不覆盖推荐，切CPM |

### 调时段

**买家画像** → 活跃时段热力图 → 看看你的预算高峰是不是跟买家高峰对上了。如果凌晨烧得多但买家凌晨不活跃 → 调整自动充值门槛和时间。

## ⚡ 快速排查卡 (30秒定位)

```
预算烧得快但订单没跟上？
  → 先看销售漏斗 → CTR低？CVR低？
  → CTR低 → 搜索请求(你的商品) → 看哪个词🟥 → 换主图
  → CVR低 → 同个报告看加购转化率🟥 → 调价

某个品突然数据变差？
  → 搜索请求 → 展开品 → 看是不是某个核心词的排名突然掉了
  → 排名掉了 → 活动内图表图标 → 看竞争出价是不是被抬高了
  → 被抬了 → 提价跟上

推荐位在烧钱但没效果？
  → 扩展统计→目录统计sheet → 看CTR
  → CTR低 → 主图在推荐流不抓眼 → 换图
  → CTR正常但CVR低 → 推荐流量本来就是种草，降低推荐出价
```

## 📢 第二篇：推广体系（付费模式 & 运作原理）

### 2.1 三种付费模式对比

| 维度 | CPM 统一出价 | CPM 手动出价 | CPC |
|------|:--:|:--:|:--:|
| **计费方式** | 每 1,000 次展示 | 每 1,000 次展示 | 每次点击 |
| **覆盖范围** | 🔍搜索 + 📂目录 + ⭐推荐 | 🔍搜索 + 📂目录 + ⭐推荐 | 🔍搜索 + 📂目录 |
| **关键词管理** | ❌ 系统自动匹配 | ✅ 可排除/固定搜索词 | ❌ 系统自动匹配 |
| **出价方式** | 统一出价 | 分区域手动出价 | 统一出价 |
| **起投金额** | ≥ 1,000 ₽ | ≥ 1,000 ₽ | ≥ 1,000 ₽ |
| **适合谁** | 新手、跑量测品 | 精细运营、有经验 | 成本敏感 |

### ⚠️ 关键规则

| 规则 | 说明 |
|------|------|
| **切换模式 → 关键词全丢** | CPM↔CPC 切换需**新建活动**，所有关键词、出价、排除词不继承 |
| **CPM + CPC 可双开** | 可同时运行两个独立活动（CPM 覆盖推荐 + CPC 覆盖搜索） |
| **CPC 不含推荐流量** | 只投搜索和目录页，不投推荐位 |
| **CPC 单活动只限同类目** | 不同类目商品需分别创建活动 |
| **预算** | 最低 1,000 ₽，可按人民币支付 |

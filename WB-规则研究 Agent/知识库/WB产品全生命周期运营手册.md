# 🎯 WB 产品全生命周期运营手册

> 基于 WB 平台规则 + 三店实际数据 + 广告推广体系  
> 适用店铺：TEN / MaxGo / Champ baby

---

## 一、产品分类体系

### 🔴 A类：测试失败品
- **定义**：上架2-4周，日展示<500，无订单或<3单/周，CTR<1%
- **特征**：花钱不出单，CPC虚高但无转化
- **典型数据**：花5000₽+，0-2单，ROI<1x

### 🟡 B类：慢热难升品
- **定义**：有稳定订单（3-10单/周），但提价/扩量后数据不跟涨
- **特征**：CTR正常(2-4%)但CVR低(<1%)，或CVR正常但曝光卡住
- **典型数据**：花20000₽，10-30单，ROI 3-10x

### 🟢 C类：快速爆单品
- **定义**：上架1-2周内出单，优化后订单指数增长
- **特征**：CTR>4%，CVR>2%，自然流量占比快速提升
- **典型数据**：花50000₽，100+单，ROI>15x

## 二、新品目标设定与投放决策（上架第一步）

> 核心逻辑：新品的目标不是"拼命优化"，而是**先看头部定个可实现的短期目标，达标就收手转回爆款**。避免在潜力有限的品上盲目优化（本末倒置）。

### 🔍 看词（判断热度与竞争）

- 看这个词 **7 天出了多少单**、热度怎么样
- 翻核心词下面的数据：**卖得最好的头部每天出多少单、7天出多少单、30天出多少单**
- 拿头部出单数当参考基准 → 定新品短期目标单量

### 🧭 两种投放思路

| 思路 | 判断方法 | 动作 |
|------|---------|------|
| **① 蓝海** | 找核心词 → 词下**没有竞品** | 新品蓝海 → **直接投广告投流做** |
| **② 有头部** | 核心词下**有竞品** → 找头部 | 拿头部 7天/30天出单数做参考基准 |

> ⚠️ 只要是产品就有关键词，有关键词就肯定有头部，头部肯定有出单数。拿参考，别盲目。

### 🎯 新品短期目标

```
目标单量 = 头部 7天出单数 为基准（可打个折扣，如 50-70%）
达标后 → 注意力转回爆款
（新品潜力有限，不看头部卖的情况盲目优化 = 本末倒置）
```

### ✍️ 优化动作（埋词）

1. **新品前期只买 1-2 个核心词**
2. **长尾词埋在热度高的详情页里**（标题/描述/属性）
3. **标题手输注意**：避免同义词堆砌、重复词（参考官方错误示例）
4. **图片 3:4**：可以抠成白底图 → 场景切换 + AI试穿都方便

## 三、新品期（上架 0-2 周）

### 📏 价格上下限评估

| 评估维度 | 怎么算 | 为什么 |
|---------|--------|--------|
| **下限** | 采购成本 + 物流费 + 佣金(按类目查) + 仓储费 + 15%安全边际 | 低于此价亏本 |
| **上限** | 同类目竞争出价对应竞品价格的 1.2-1.5 倍 | WB 禁止超过平均价500%（合约5.9.1.3），但建议不超过150% |
| **参考价** | 同类目 TOP 10 竞品的中位数价格 | 这是买家心理价位 |

> ⚠️ WB 价格以人民币设置，按内部汇率转卢布（日更，波动≤央行±10%）。改价即时生效。

### 📋 平台约束
- ❌ **上架≤15天不可参加促销**
- ❌ 不可声称疗效（尤其 Champ baby 产品）
- ❌ 不能缺货：120小时 FBS 交付期限，缺货后转化率不归零但排名会掉

### 📢 广告策略

| | **A类测试品** | **B类慢热品** | **C类潜力品** |
|------|:--:|:--:|:--:|
| **模式** | CPM 自动 | CPM 自动 | CPM 自动 |
| **出价** | 竞争出价 | 竞争出价×1.2 | 竞争出价×1.5 |
| **预算/天** | 300-500₽ | 500-800₽ | 800-1500₽ |
| **目标** | 验证是否有需求 | 积累5000展示看数据 | 快速积累数据 |
| **止损线** | 花5000₽无单→停 | 花10000₽ CVR<1%→诊断 | 持续跑 |

### 🔑 新品期关键动作
1. **优化商品详情页**：5张以上高质量图、完整描述、精准类目
2. **检查搜索排名因素**：7要素红绿灯 → 优先修🟥项
3. **不碰促销**：等15天解锁
4. **用欢迎积分**：如果还有10,000积分额度，优先烧积分不烧余额

## 四、上升期（上架 2-6 周）

> 判断标准：累计展示>7000，日订单≥5，CTR>3%

### 📏 价格调整
- C类产品可提价 5-15%（需求验证通过后提价）
- B类产品维持原价，先优化转化
- A类（如果活下来了）维持低价冲量

### 📢 广告策略升级

| | **B类慢热品** | **C类爆品** |
|------|:--:|:--:|
| **模式** | 切 CPM 手动 | CPM 手动 + CPC 双开 |
| **出价** | 领导者出价 | 领导者出价→逐步试Top-2 |
| **关键词** | 分析搜索词→排除无效词→固定高转化词 | 下载搜索集群→高转化集群提价 |
| **预算** | 1000-2000₽/天 | 2000-5000₽/天 |
| **降低系数** | ✅ 开启 | ✅ 开启 |

### ⚠️ 切换手动出价的陷阱
> 🔴 **切换出价模式 = 新建活动 → 关键词全部清零！**  
> 建议：保留原 CPM 自动活动跑着，新建 CPM 手动活动做精细化

### 🔑 上升期关键动作
1. **排除不相关搜索集群**：100次展示门槛达标后操作
2. **分析搜索词报告**：找出CTR高但CVR低的词→优化详情页；找出CTR低但CVR高的词→优化主图
3. **A/B测试主图**：Jam订阅标准版5次/月、高级版10次
4. **鼓励评论**：使用"评论积分"工具
5. **参加促销**：15天锁定期过后立即参加合适的促销活动

## 五、爆单期（销量峰值阶段）

> 判断标准：日订单>20，自然流量占比>40%，ROI>15x

### 📏 价格策略
- **可继续提价**：每次 3-5%，隔 2-3 天观察销量变化
- 目标：找到利润最大化的价格点（销量×单利最大值）
- ⚠️ 不要一次性提太多，可能触发"价格异常"检测（合约 5.9.1.3）

### 📢 广告策略

| 维度 | 策略 |
|------|------|
| **模式** | CPM手动(主力) + CPC(辅助) |
| **出价** | Top-2 出价抢首屏 |
| **预算** | 不设硬上限，设自动充值 |
| **关键词** | 高转化集群持续提价，扩大固定词库 |
| **降低系数** | ✅ 目录/推荐开启 |

### 🔴 库存风险管理（关键！）

```
预警公式：当前库存 ÷ 日均销量 = 可售天数
```

| 可售天数 | 行动 |
|:--:|------|
| >30天 | 正常跑，不用管 |
| 15-30天 | 提价 5-10%，降低广告出价 20% |
| 7-14天 | 提价 15-20%，广告降到最低出价或暂停 |
| <7天 | 🚨 暂停所有广告，大幅提价 30%+ |

> ✅ 断货影响不是灾难：转化率不归零（从断货前最后值恢复），评分/评论保留。  
> ⚠️ 但销量排名会掉，恢复库存后需重新冲量。

### 🔑 爆单期关键动作
1. **监控库存**：按上面的预警表操作
2. **富媒体内容**：加推广模块（每月20次免费，Jam可扩）
3. **买家画像报告**：看受众活跃时段，广告集中投放在高峰时段
4. **关联转化利用**：爆品带动的14天关联转化不额外收费
5. **替代商品编号**：追踪不同渠道效果

## 六、稳定期（销量平稳阶段）

> 判断标准：日订单稳定在某个区间，波动<20%，ROI>10x

### 📏 价格策略
- 维持当前价格
- 试小幅降价 3-5% 看能否再激发一波增长
- 竞品降价时跟不跟？跟一半（竞品降10%你跟5%）

### 📢 广告策略

| 维度 | 策略 |
|------|------|
| **模式** | 维持 CPM 手动 |
| **出价** | 从领导者出价逐步降到竞争出价 |
| **预算** | 固定预算，不设自动充值 |
| **优化方向** | **降花费占比**，提升 ROI |

### 🔑 稳定期关键动作
1. **压缩 CPC**：逐步降低出价，观察排名变化
2. **扩展品类**：用关联转化数据找可交叉销售的新品
3. **市场分析报告**（需Jam高级版）：找新细分市场
4. **清理低效SKU**：关闭ROI<5x的SKU广告

---

## 七、下落期（销量持续下滑）

> 判断标准：连续2周日均订单下降>30%

### 📢 策略选择

| 路径 | 适用 | 操作 |
|------|------|------|
| **抢救** | 季节性波动、竞品降价导致 | 参加大促、加投CPC、优化详情页 |
| **维持** | 还有利润但不再增长 | 降广告预算50%，维持自然流量 |
| **清退** | ROI跌破盈亏线 | 停广告、降价清仓、腾出预算给新品 |

## 九、三个差异化策略

### 🔴 A类失败品处理 SOP

1. **先诊断后决定**（不要立刻停）
   - 检查7因素红绿灯：哪个是🟥？
   - CTR<1% → 主图问题，换图测A/B
   - CTR正常但CVR<1% → 详情页/价格/评论问题
   - 展示量都不够 → 出价太低或类目太卷

2. **止损线**：花费>5000₽ 且 订单<3 → 暂停广告
3. **暂停后选择**：
   - 降价30%+清仓
   - 或换类目/换主图/换标题重新上
   - 或直接下架，预算转移给B/C类

### 🟡 B类慢热品突破 SOP

1. **7因素诊断**（逐项排查）
   - 物流配送🟥？→优化仓库选择，缩短配送时间（影响排名30-40%）
   - 促销参与🟥？→等15天锁定期后立即参加促销
   - 转化率🟥？→优化详情页、加富媒体内容、降低价格
   - 评分🟥？→用评论积分工具鼓励买家评价

2. **如果7因素全🟩但仍不涨**
   - 可能是类目天花板低 → 查"WB搜索请求"报告看类目需求量
   - 可能竞品太强 → 查竞品价格/评分/配送，找差异化切入点
   - 加投 CPC 补充搜索流量

3. **3周后仍无突破** → 降为稳定期策略，保利润而非冲量

### 🟢 C类爆品放大 SOP

1. **库存先行**：先确保供应链能跟上，再放量
2. **价格阶梯**：每提价5%观察2天，找到利润峰值
3. **广告三通道**：
   - CPM手动（搜索+目录）：领导者出价，争排名
   - CPC（搜索补充）：低出价兜底长尾词
   - 促销活动：匹配最高折扣力度
4. **关联转化利用**：爆品详情页加"卖家推荐"模块，交叉导流
5. **市场分析**：查同类目竞品，看天花板还有多高

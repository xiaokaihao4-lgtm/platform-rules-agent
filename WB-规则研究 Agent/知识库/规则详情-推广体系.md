## 一、三种付费模式

| 维度 | CPM 统一出价 | CPM 手动出价 | CPC |
|------|:--:|:--:|:--:|
| 计费 | 每1000次展示 | 每1000次展示 | 每次点击 |
| 覆盖 | 搜索+目录+推荐 | 搜索+目录+推荐 | 搜索+目录 |
| 最低起投 | 1,000₽ | 1,000₽ | 1,000₽ |
| 最低出价 | 30-230₽ | 40-500₽ | 按子类目 |
| 关键词 | ❌ 系统自动 | ✅ 可排除/固定 | ❌ 系统自动 |
| 适合 | 新手/跑量 | 精细运营 | 成本敏感 |
| 排除请求 | ✅ 可排除集群 | ✅ 可排除集群 | ❌ 不可 |

**铁律：**
- 切换模式 = 新建活动 → 关键词全部丢失
- CPM + CPC 可同时双开（独立活动）
- CPC单活动只能放同类目商品
- **启动后不可切换统一/手动费率**

### CPC 点击定义（2026-06-25 更新 ⚠️）

官方已更新 CPC 的「点击」定义，**不再只是进入详情页**：

| 计入 CPC 点击的操作 | 是否扣费 |
|---------------------|:---:|
| 进入商品详情页 | ✅ 扣费 |
| 点击「快速预览」按钮 | ✅ 扣费 |
| 从搜索结果页加入购物车 | ✅ 扣费 |
| 从搜索结果页加入收藏夹 | ✅ 扣费 |
| 详情页内操作（选尺码/加购） | ❌ 不扣费 |

**关键规则：**
- 买家在搜索结果页**多次点击 = 多次分别扣费**（如先加收藏再加购物车，扣2次）
- 详情页内的点击（选尺码、详情页内加购）不扣费
- CPC 覆盖区域**仍是搜索+目录，不覆盖推荐**（这条没变）

**对卖家的影响：** CPC 成本结构变贵了——以前搜索页的加购/收藏是免费的，现在都算点击计费。想投推荐流量仍需 CPM。

## 二、活动创建流程（7步）

1. **创建活动** — 推广→WB推广→+创建活动→命名
2. **选择付费模式** — CPM或CPC
3. **指定预算** — 最低1000₽，可设自动充值
4. **选择展示区域** — CPM统一价无需选；手动价需选区域
5. **添加商品** — 每活动最多**50个同类目商品**，支持CSV/XLSX批量上传
6. **为每个商品设出价** — 手动模式需分区域分别设价
7. **充值预算启动** — 选统一账户或推广积分

### 启动后可编辑项
| 操作 | CPC | CPM统一 | CPM手动 |
|------|:--:|:--:|:--:|
| 修改名称 | ✅ | ✅ | ✅ |
| 自动充值 | ✅ | ✅ | ✅ |
| 增删商品 | ✅ | ✅ | ✅ |
| 修改出价 | ✅ | ✅ | ✅ |
| 排除请求 | ❌ | ✅ | ✅ |

## 三、出价机制详解

### 出价计算公式
```
最低出价 = 基础出价 × 系数
```
- 系数反映竞争程度（目前所有系数均为1，更新时会有通知）
- 暂停重启/编辑设置/充值后，出价自动更新为新最低值

### 四档参考出价
| 指标 | 含义 | 数据来源 |
|------|------|---------|
| **最低出价** | 系统允许的最低价 | 按类目计算 |
| **竞争出价** | 同类商品中位数出价 | 过去24h有展示的出价 |
| **领导者出价** | 领先卖家平均出价 | 过去24h高展示+高点击的出价 |
| **顶级出价** | 争前2名的出价 | 测试中，非全类目可用 |

- 添加商品时系统自动设为竞争出价，可手动调整
- **竞争出价 = 中位数**：一半卖家高于它，一半低于它
- **领导者出价**：展示和点击显著高于竞争出价的卖家
- **顶级出价**：仅前2个位置，CTR比第50位高2倍+（测试中）

### CPM手动模式的降低系数
- 目录和推荐区域适用降低系数
- 同等预算 → 实际展示成本更低 → 更多展示

## 四、预算与支付

| 项目 | 规则 |
|------|------|
| 最低预算 | **1,000₽**（建议3,000₽起步） |
| 充值来源 | ①WB推广账单 ②推广积分 |
| 充值路径 | 主页→提现→选0%-60%转入推广账户 |
| 到账时间 | 推广账户**当日**、支付系统**5工作日** |
| 提现限制 | **不能只转推广不转支付系统**（可全转支付不转推广） |
| 技术误差 | 百分比与实际划转差额 <1% |
| 调整预算 | 可随时增加，可提前结束退回剩余 |
| 自动充值 | 可设条件和支付来源，避免展示中断 |

### 推广积分
- 入驻费 = 返还为推广积分，**1年有效期**
- 活动结束后未用积分 **1天内返还**（未过期前提下）
- 已用积分不提供结算文件
- 查看路径：我的积分板块

### 支付状态
- 🟢 支付成功（绿色）
- ⚫ 正在处理（黑色）
- 🔴 支付失败（红色）

## 五、搜索排名逻辑

### 自然搜索排名因素
| 排名因素 | 影响 |
|---------|------|
| 配送时间 | 🔥 影响30-40%排名 |
| 销量 | 越高越好 |
| 促销活动参与度 | 加分 |
| 商品详情页质量 | 图片/描述/属性 |
| 评分和评论 | 越高越好 |
| **转化率** | 🔥 最关键！动态变化 |

### 核心公式
```
推广展示位置 = 自然权重 × 出价权重
```
- 付费推广**仅是对自然排名的补充**
- 排名低+出价高 ≠ 能进前位
- 搜索结果**个性化**（不同用户/地区看到不同）
- 排名位置实时变化，受多方因素影响

### 自然流量 vs 付费流量
- ✅ 商品完全可以仅靠自然流量成功
- 推广是**辅助工具**，非必要条件
- 自然增长 = 吸引力定价 + 优质内容 + 好体验

### 新品推广四步走
1. 统一出价活动（CPM自动），参考竞争出价
2. 积累 5,000-7,000 展示 → 分析搜索词和转化率
3. 表现好的商品开手动出价 → 排除不相关词 → 中等频率词起步
4. 持续监控 → 逐步优化关键词降低成本

### 预算消耗快的原因
- 高竞争关键词 + 出价过高
- 季节性需求高峰
- 商品自然排名低需更高出价
- 活动期流量激增

## 六、统计报表指标全览

### 核心KPI（按推广活动）
| 指标 | 公式 | 用途 |
|------|------|------|
| 展示次数 | — | 商品被看到的次数 |
| 点击次数 | — | 进入详情页/加购/收藏（仅搜索结果页） |
| **CTR** | 点击÷展示×100 | 关键词-商品匹配度 |
| **CPC** | 花费÷点击 | 点击成本控制 |
| **CR** | 订单÷点击×100 | 转化效果 |
| **花费占比** | 花费÷订单金额×100 | ROI判断(<100%=盈利) |
| **CPM** | 花费÷展示×1000 | 展示成本 |
| **CPO** | 花费÷订单 | 单均获客成本 |
| **平均排名** | — | 搜索/目录位置 |
| 取消数 | — | 技术原因未送达+1h内取消 |
| 加购次数 | — | 含14天关联转化 |
| 订单数 | — | 含14天关联转化 |

### 关联转化（重要！）
- 买家点击推广商品后**14天内**加购/下单你店铺其他商品
- 计入"加购次数"和"订单数"指标
- **不额外收费**，只对推广商品展示付费

### 报表类型
| 报表 | 内容 |
|------|------|
| 总体统计 | 所有活动汇总，可下载XLS |
| 活动统计 | 折线图+销售漏斗+基础统计表 |
| 销售漏斗 | 展示→点击→加购→订单，四阶段分析 |
| 扩展统计XLSX | 5个选项卡：总体/关键词/目录/曝光提升/关联转化 |

### 活动统计特有指标
- 平均排名、订单金额、活动起止日期
- 合并商品详情页的总指标+单品指标

### 销售漏斗优化
| 目标 | 方法 |
|------|------|
| 更多展示 | 优化标题/描述 + 检查排除词 + 提高出价 + 缩短配送 |
| 更多点击 | 优化主图 + 检查价格竞争力 + 排除低CTR词 |
| 更多加购/订单 | 5张以上高质量图 + 鼓励评论 + 回复买家 + 缩短配送 |

### 为什么没有展示？
- 活动暂停/结束、预算耗尽、多活动竞争、商品缺货、评分过低被隐藏

## 七、促销活动

### 参与促销的好处
- 搜索结果和目录更高排序
- 专属标识 + 红色价格
- 首页横幅曝光
- "促销"筛选项可见

### 核心规则
- ⚠️ **上架≤15天的新品不可参与促销**
- 通过促销日历或"价格与折扣"板块管理参与
- 多尺码商品：促销折扣按最高售价统一计算，所有尺码同比例降价

### 参与条件
- "是" = 当前价格≤促销价，自动参与
- "否" = 当前价格>促销价，需降价或设折扣
- 状态：未参与 / 参与
